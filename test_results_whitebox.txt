[CRITICAL] 14 SQL injection risks in app/db/init_db.py
  Severity: HIGH
  Location: app/db/init_db.py lines 83, 725, 740, 780, 795, 1129, 1174, 1191,
            1219, 1250, 1278, 1309, 1344, 1369
  Detail: f-string used to construct ALTER TABLE / CREATE INDEX SQL statements.
          While these are likely internal migration helpers (not user-facing),
          they still pose a risk if any variable is derived from user input.
  Recommendation: Use parameterized queries or validate/sanitize all variable
          inputs before interpolation. Consider using alembic for all schema
          changes instead of ad-hoc DDL in init_db.py.

[HIGH] 215 of 276 API routes (78%) lack try/except error handling
  Severity: HIGH
  Location: All files under app/api/routes/
  Detail: The majority of route handlers delegate error handling to FastAPI's
          global exception handler. While this works for common exceptions,
          it may expose stack traces or internal details to clients.
  Recommendation: Add try/except blocks to critical routes (especially POST/PUT/
          DELETE operations). Ensure global exception handler sanitizes error
          messages before returning to clients.

[HIGH] 469 TypeScript `any` usages in frontend
  Severity: MEDIUM
  Location: Throughout frontend/src/ (all .ts/.tsx files)
  Detail: Extensive use of `any` type undermines TypeScript's type safety.
          Common patterns: `error: any` in catch blocks, `any[]` for API
          response data, `as any` type casts.
  Recommendation: Define proper interfaces for API responses. Use `unknown`
          instead of `any` for catch block errors. Enable strict ESLint rules
          to prevent new `any` introductions.

[MEDIUM] 19 database models missing index definitions
  Severity: MEDIUM
  Location: app/models/ (ai_profile, akshare_api_config, alert, async_task,
            backtest, custom_indicator, discovery, discovery_plan, etc.)
  Detail: Models without explicit indexes may suffer from slow queries as data
          grows. SQLAlchemy defaults to indexing only primary keys.
  Recommendation: Add __table_args__ with Index definitions for frequently
          queried columns (e.g., foreign keys, status fields, timestamp fields).

[MEDIUM] 22 potential N+1 query patterns (relationships without eager loading)
  Severity: MEDIUM
  Location: app/models/ (ai_session, daily_bar, factor_model, portfolio, scan,
            scheduled_task, score, symbol, universe)
  Detail: SQLAlchemy relationships default to lazy loading, which triggers
          additional queries when accessing related objects in loops.
  Recommendation: Use joinedload() or selectinload() in queries that access
          related objects. Add lazy="joined" or lazy="selectin" to frequently
          accessed relationships.

[MEDIUM] 21 useEffect hooks missing cleanup functions
  Severity: MEDIUM
  Location: frontend/src/ (App.tsx, AiChatDrawer.tsx, AlertCenter.tsx,
            CustomIndicatorSettings.tsx, DbConfigSection.tsx, MacroData.tsx,
            MarketNews.tsx, UniverseDataPanel.tsx, AISettings.tsx, etc.)
  Detail: useEffect hooks that set up timers, subscriptions, or async operations
          without cleanup can cause memory leaks and stale state updates.
  Recommendation: Add cleanup return functions to all useEffect hooks that use
          setTimeout, setInterval, addEventListener, or async operations.
