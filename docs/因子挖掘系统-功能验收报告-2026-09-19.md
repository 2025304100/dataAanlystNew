## 三、未达标项差异明细（优先修复清单）

### P0 — 阻断性（端到端不可用，对应 M1 验收标准 1/4/15）

1. **真实适应度评估缺失**：[evaluation_adapter.py](../app/services/factors/mining/evaluation_adapter.py#L275-L287) `evaluate_short` 仅签名无实现（应接入 FactorExecutor + factor_evaluator.compute_rank_ic/coverage/turnover + G2 缓存）。这是"三段切分/适应度只用 train"真正生效的前提。
2. **GA 主循环未接入任务 worker**：[task_runner.py](../app/services/factors/mining/task_runner.py#L261-L269) `_default_stage_runner` 是占位骨架；需注入 `initial_population → run_ga_loop → finalize_run` 完整阶段链并接入 `evaluate_short`。
3. **20+ 核心 API 为占位**：[factor_mining.py](../app/api/routes/factor_mining.py) runs 创建/查询/取消/暂停/恢复/停止/放弃、generations/candidates/lineage、ai/generate-preview、evaluations/evaluate-all、save-as-template、grade/manual|restore-auto|evidence 全部 `NotImplementedError` → 前端无法发起或跟踪任务。
4. **前端提交接线断裂**：`MiningShell.onSubmitted` 未由 Settings 传参；Step4 确认后无任何调用；Step5/结果页无数据源。

### P1 — 高（M2 关键特性落不了地）

8. **草稿/最终准备校验/模板管理/清理接口整体缺失**（drafts/prepare/templates/formula-templates/cleanup 路由全缺）。
