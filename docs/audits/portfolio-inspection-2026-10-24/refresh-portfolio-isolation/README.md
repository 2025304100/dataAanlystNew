# 检查与对账：刷新与组合切换的浏览恢复

2026-10-24，最终前端资源，只读验收。后端规则与放行资格不改。

浏览状态改为按组合、页面和关联范围分别保存于本标签页sessionStorage，有效期24小时。恢复组合必须仍在真实列表中；明确指定其他一级模块的URL优先。存储被禁用、损坏、过期或时间异常时回退正常读取。

## 修复内容

- 原先只有内存态和跨模块临时返回记录，不能覆盖一般刷新；数据搜索单一槽位也会覆盖别的组合草稿。现在抽屉栈、所选日期、数据搜索、历史筛选（含未提交草稿）、分页数量、详情引用、展开与滚动分作用域保存。
- 切换组合重新建立检查会话，旧组合的深链、浮层、报告、请求与选择不传入新组合；返回时恢复原组合自身的浏览元数据。
- 刷新检查页返回原组合和原查看位置。每日对账关闭后重开保留所选日期，快捷核对与下层执行日期独立。
- 报告、状态、运行权限、完成证明、审批勾选及确认弹窗不作为浏览状态缓存或重放。普通浏览恢复不沿用审核理由或授权；既有跨模块明确返回草稿流程保持原契约。
- 历史分页先读取新水位，再在该水位下重建已加载页；原材料按确切引用重新读取。记录变化不会借缓存显示通过。
- 异步内容到齐后恢复位置与展开；加载占位不覆盖原展开项，pagehide即时保存最后操作。关闭限定到发起浮层，已关闭工作台不凭空恢复成引导状态。
