# 前端只读验收状态、操作禁用与跨场景一致性（2026-10-24）

## 实现

应用在React挂载前启动统一服务模式读取，使用无缓存GET，所有组合与浮层订阅同一状态。服务统一提供模式元数据：验收服务明确只读；普通应用明确mode=application/read_only=false，该值不代表任何交易权限。404、缺字段、不合法结果和网络错误不能推断为普通模式。

页面、检查抽屉、快捷弹窗及独立数据修复区明确显示“只读验收模式”，说明登记、重检、修复和审核禁用，查看与历史可用。32处修改操作/确认入口使用显式mutation意图：补证登记/审核、原请求重试、对账重检、修复预览/提交/重试/停止、绑定/运行审核、基线登记/接受、双跑启动及引擎切换确认等。禁用按钮保留可见原因及辅助说明；统一按钮转发ref，保留现有Tooltip与焦点兼容。没有按按钮名称或整片区域粗暴禁用。

查看详情、查询/筛选历史、重新读取诊断/作业/原请求、历史导出、导航、关闭和返回保留。审核页入口可打开查看，真正的提交确认禁用。首次模式未知和模式读取失败时先阻止修改；已知只读后遇到服务不可读继续保留只读，并明确提示。可手动重新读取，不自动重放请求。

模式每15秒可见时补查，并在焦点、联网、页面恢复和组合会话挂载时核实；读取合并，旧响应失效后不能覆盖只读结论。模式不按组合存储，不持久缓存“可写”权限；刷新/重进先核实。请求层在fetch前再保护所有修改方法，覆盖旧闭包/键盘等遗漏；可信只读423信号会使旧模式读取失效。服务端三层只读保护继续独立生效。
