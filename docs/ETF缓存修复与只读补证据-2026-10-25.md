### 可复制的只读 SQL

完整脚本：[ETF缓存修复只读回归-2026-10-25.sql](D:/ai_project/dataAanlystNew/docs/ETF缓存修复只读回归-2026-10-25.sql)。包括 159 表行数、关键字段 NULL/空串、三行缓存、三行其他全部字段、全部 ETF 缓存一致性、版本和空闲任务检查。所有 `_match/_matches` 必须为 1。

```sql
USE gpfx_validation;
SET TRANSACTION READ ONLY;
START TRANSACTION WITH CONSISTENT SNAPSHOT;

-- 必须恰为三行，且缓存与实际行情统计一致。
SELECT u.id, u.symbol, u.bar_count, COUNT(b.id) AS actual_count,
       u.last_bar_date, MAX(b.trade_date) AS actual_latest,
       (u.bar_count <=> COUNT(b.id)) AS count_matches,
       (u.last_bar_date <=> MAX(b.trade_date)) AS date_matches
FROM universe_symbols u
LEFT JOIN universe_daily_bars b ON b.universe_symbol_id=u.id
WHERE u.id IN (6549,6604,7098)
GROUP BY u.id,u.symbol,u.bar_count,u.last_bar_date;

SELECT COUNT(*) AS actual_rows, 11734896 AS expected_rows
FROM universe_daily_bars;
SELECT version_num FROM alembic_version;
SELECT COUNT(*) AS active_tasks
FROM async_tasks WHERE status IN ('running','queued');
ROLLBACK;
```
