## 0087隔离验收SQL

下面仅用于显式选中的`codex_combination_*`验收库。迁移/恢复必须由现有脚本创建新库并保留证据，不能将此检查改成修改历史数据的SQL。预检与迁移后各保存一份列元数据；`action`字符集/排序规则应与预检相同，长度至少64，三个DATETIME精度均为6。

```sql
SELECT DATABASE() AS isolated_database, VERSION() AS server_version;
SELECT version_num FROM alembic_version;
SELECT c.TABLE_NAME, c.COLUMN_NAME, c.DATA_TYPE,
       c.CHARACTER_MAXIMUM_LENGTH, c.DATETIME_PRECISION,
       c.CHARACTER_SET_NAME, c.COLLATION_NAME,
       c.IS_NULLABLE, c.COLUMN_DEFAULT, c.COLUMN_COMMENT, t.ENGINE
FROM information_schema.COLUMNS AS c
JOIN information_schema.TABLES AS t
  ON t.TABLE_SCHEMA = c.TABLE_SCHEMA AND t.TABLE_NAME = c.TABLE_NAME
WHERE c.TABLE_SCHEMA = DATABASE()
  AND ((c.TABLE_NAME = 'factor_model_audit_logs' AND c.COLUMN_NAME = 'action')
    OR (c.TABLE_NAME = 'portfolio_factor_usages'
        AND c.COLUMN_NAME IN ('effective_from', 'effective_to'))
    OR (c.TABLE_NAME = 'strategy_execution_snapshots'
        AND c.COLUMN_NAME = 'effective_from'))
ORDER BY c.TABLE_NAME, c.COLUMN_NAME;
SELECT action, CHAR_LENGTH(action) AS action_length, COUNT(*) AS rows_count
FROM factor_model_audit_logs GROUP BY action ORDER BY action;
```

行数、最大长度和校验和只能辅助诊断，不能替代完整行/列比较。本轮迁移回归在新库保存四张相关表全部原行、索引和列元数据后比较；恢复回归与源库保护进一步比较所有158表和仓库摘要，禁止用GROUP_CONCAT等可能截断的SQL拼接来证明“无丢行”。通过标准还包含原始33字符动作完整往返、`.800000`即时绑定审核、重入无变化、拒绝缩窄和拒绝漂移时无部分DDL。
