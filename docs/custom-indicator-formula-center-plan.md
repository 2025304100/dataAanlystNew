# 全局自定义指标与公式中心改良计划

## 背景

当前高级公式主要放在回测条件里，可以快速验证策略，但不利于长期复用。后续机会挖掘、回测、预警、复盘都会用到同一批指标，所以需要把公式能力抽成全局模块。

建议新增一个设置页签：**设置 -> 指标公式**。用户在这里维护自定义指标，其他业务模块只引用指标，不重复写公式。

## 建设目标

1. 公式定义从回测配置中抽离，成为全局指标库。
2. 内置技术指标和自定义指标统一管理、统一引用。
3. 回测、机会挖掘、信号筛选、预警、复盘都可以使用同一套指标。
4. 支持参数化、试算、启用/停用和版本追踪。
5. 保持公式执行安全：使用受限表达式，不直接执行任意 Python 代码。

## 改良计划表

| 阶段 | 优先级 | 改良项 | 目标 | 主要产出 |
|---|---|---|---|---|
| 1 | P0 | 新增“指标公式”设置页签 | 把高级公式从回测里抽出来 | 设置页独立页签、指标列表、编辑入口 |
| 2 | P0 | 自定义指标库 | 用户可以保存公式 | 指标名称、Key、公式、说明、返回类型、启用状态 |
| 3 | P0 | 回测条件引用指标库 | 回测规则选择已保存指标 | 条件字段支持 `custom_indicator` 引用 |
| 4 | P0 | 公式安全执行引擎统一化 | 回测和后续模块共用同一套求值逻辑 | `indicator_engine` 服务层 |
| 5 | P1 | 公式参数化 | 同一公式可按周期、阈值复用 | 参数定义、默认值、规则内覆盖参数 |
| 6 | P1 | 公式试算/预览 | 写公式时能立即看最近结果和错误 | 选择股票、日期范围、最近 N 日结果表 |
| 7 | P1 | 接入机会挖掘 | 机会挖掘可以筛选自定义指标 | 挖掘条件支持内置指标 + 自定义指标 |
| 8 | P1 | 接入信号筛选/预警 | 指标触发可生成提醒 | 预警规则引用指标，支持阈值触发 |
| 9 | P2 | 指标版本管理 | 修改公式不影响旧回测和历史结果 | 指标版本表、规则绑定版本 |
| 10 | P2 | 接入复盘 | 复盘展示当时指标状态 | 交易记录/复盘记录关联指标快照 |

## 页面设计

入口：`设置 -> 指标公式`

| 区域 | 内容 | 说明 |
|---|---|---|
| 左侧指标列表 | 指标名称、分类、启用状态、更新时间 | 支持搜索和按分类筛选 |
| 中间编辑区 | 名称、Key、分类、返回类型、公式、参数 | 公式编辑主区域 |
| 右侧试算区 | 股票、日期范围、最近 N 日结果 | 用于确认公式真实可用 |
| 底部应用范围 | 回测、机会挖掘、预警、复盘 | 控制指标在哪些模块出现 |

## 数据模型建议

### `custom_indicators`

| 字段 | 说明 |
|---|---|
| `id` | 主键 |
| `name` | 指标名称 |
| `key` | 稳定引用 Key，如 `strong_trend_filter` |
| `description` | 指标说明 |
| `category` | 分类：trend/momentum/volume/risk/custom |
| `formula` | 受限表达式公式 |
| `value_type` | `number` 或 `boolean` |
| `params_json` | 参数定义 JSON |
| `scope_json` | 可用范围：backtest/discovery/alert/review |
| `enabled` | 是否启用 |
| `created_at` / `updated_at` | 创建和更新时间 |

### `custom_indicator_versions`

| 字段 | 说明 |
|---|---|
| `indicator_id` | 指标 ID |
| `version` | 版本号 |
| `formula` | 当时公式 |
| `params_json` | 当时参数定义 |
| `value_type` | 当时返回类型 |
| `created_at` | 版本创建时间 |

## 规则引用格式

业务规则不重复保存完整公式，推荐保存指标引用。

```json
{
  "field": "custom_indicator",
  "operator": "eq",
  "value": true,
  "params": {
    "indicator_key": "strong_trend_filter",
    "version": 3,
    "overrides": { "short": 5, "long": 20 }
  }
}
```

## 公式能力范围

建议首批支持：`open`、`high`、`low`、`close`、`volume`、`amount`、`turnover_rate`、`prev_close`、`quality_score`、`timing_score`、`trend_score`、`momentum_score`。

建议首批函数：`sma`、`ema`、`rsi`、`macd`、`macd_signal`、`macd_hist`、`boll_upper`、`boll_mid`、`boll_lower`、`atr`、`kdj_k`、`kdj_d`、`kdj_j`、`highest`、`lowest`、`ref`、`pct_change`、`volume_ratio`、`cross_over`、`cross_under`。

### 公式示例

```text
sma(20) > sma(60) and rsi(14) < 70
```

```text
cross_over("ma5", "ma20") and volume_ratio(20) > 1.5
```

```text
close > boll_upper(20, 2) and macd_hist() > 0
```

## 跨模块接入设计

### 回测

回测高级条件中新增 `Custom Indicator`。用户选择设置页中保存的指标，回测记录保存指标 Key、版本和参数覆盖。

### 机会挖掘

机会挖掘筛选条件支持内置评分、内置技术指标和自定义指标。结果列表展示命中的指标和触发原因。

### 预警

预警规则可以引用指标，例如 `close < custom_stop_line` 或 `trend_breakdown = true`。

### 复盘

复盘页展示买入/卖出时指标快照，保留当时的计算结果和版本。

## 实施顺序

### P0：先打通全局指标库

1. 新增 `custom_indicators` 表和 CRUD API。
2. 新增设置页“指标公式”。
3. 回测高级条件支持引用已保存指标。
4. 保留当前 `Custom Formula` 作为快速试验入口。

### P1：接入机会挖掘和试算

1. 指标编辑页增加试算功能。
2. 机会挖掘条件支持选择自定义指标。
3. 机会挖掘结果展示命中的自定义指标。
4. 公式错误提示结构化展示。

### P2：版本、预警、复盘

1. 指标版本管理。
2. 回测和机会挖掘绑定指标版本。
3. 预警规则接入自定义指标。
4. 复盘展示指标快照。

## 验收标准

| 项目 | 标准 |
|---|---|
| 设置页 | 可以新增、编辑、删除、启用/停用自定义指标 |
| 公式安全 | 非允许语法、未知变量、危险调用会被拒绝 |
| 回测 | 可以选择已保存指标作为买入/卖出条件 |
| 保存 | 回测模板保存后，指标引用和参数覆盖不丢失 |
| 机会挖掘 | 可以用自定义指标过滤机会列表 |
| 试算 | 指标编辑页能显示最近 N 日结果或明确错误 |
| 追溯 | 历史回测能知道使用了哪个指标版本 |

## 风险与约束

1. 不建议开放任意 Python 代码执行，即使是个人本地工具也容易误操作文件、网络或系统命令。
2. 公式表达式要稳定、可解释、可复盘，优先支持受限表达式和白名单函数。
3. 指标版本管理不要拖太久，否则后续回测结果会缺少可追溯性。
4. 机会挖掘接入时要注意性能，自定义指标最好按股票和日期批量计算，避免逐条件重复计算。

## 推荐下一步

优先做 P0：新增 `custom_indicators` 表和 CRUD API，新增设置页“指标公式”，并让回测高级条件可以引用已保存指标。当前 `Custom Formula` 保留为快速试验入口，但正式策略建议迁移到指标库。
