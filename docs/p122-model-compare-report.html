一、功能架构与模块分工 FactorModelPage.tsx

  • 入口 ① 多选：候选模型表 rowSelection Checkbox，上限 3 个；选中不足 2 时按钮 disabled。
  • 入口 ② 对比按钮：点击前触发「预取 scoringGetModelDetail」，填充 modelDetailMap（避免 Drawer 内拿不到权重）。
  • 指标对比：基础指标 + 超参 + 训练/验证时间窗 + 训练数据截止日 + 门禁拒绝原因（Pre/Post/Legacy 分色 Tag）。
  • 因子对比：按 factor_code 聚合 AggFactor，按 maxDeltaW（跨模型 max-min）降序；单边存在因子惩罚 delta=自身权重。
  • N=2 增强：显示 Δw 绝对差 (#1→#2) + 相对变化率，并用红/橙/默认 3 档色标。
  • 多模型通用：侧列列 #1~#3 权重 + 存在性点 + side 方向不一致用 ‼ 胶囊预警。
