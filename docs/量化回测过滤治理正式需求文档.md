# 量化回测过滤治理正式需求文档

> 版本：v1.0
> 日期：2026-08-30
> 状态：开发基线
> 适用范围：A 股日线回测、因子评价、组合调仓和净值计算

## 1. 目标与边界

本方案用于保证回测结果与当日可交易条件一致，重点解决次新股、ST、停牌、退市、缺失数据和异常数据造成的虚假成交、未来函数和幸存者偏差。

生产回测默认启用全部过滤规则。开关仅用于运行级消融实验，不允许按股票、日期或单笔交易添加例外。任何关闭开关的运行都必须在结果中标记为“非保真实验”，不得与正式回测混称。

本期只覆盖 A 股日线。分钟级成交、涨跌停队列、盘中 ST 状态和交易所特殊处置细节不在本期承诺范围内；没有可靠时效数据时，系统必须提示“无法判定”并阻止正式回测，而不是猜测。

## 2. 核心原则

1. **Point-in-Time**：在交易日 `t` 只能使用 `t` 及之前已发布的数据。证券状态、上市日期、退市日期和股票池成员均按历史时点读取。
2. **先过滤、后选股、再交易**：过滤发生在候选股票进入策略调仓逻辑之前；持仓清算发生在新开仓和调仓之前。
3. **缺失不等于零**：停牌、无成交、无未来标签、价格异常均不得用 0、前值或因子自身变化代替。
4. **保留历史、限制交易**：退市股票的历史行情保留；只限制退市后的可交易行为。
5. **证据可回查**：每次排除、跳过、清算和数据降级都记录股票、日期、规则、原始值和配置版本。
6. **结果可复现**：回测必须保存过滤配置快照、状态数据版本、行情截止日、目标标签批次和执行代码版本。

## 3. 统一配置

配置类是回测全链路唯一来源，禁止在选股、调仓、清算模块中再读取散落的全局变量。

```python
@dataclass(frozen=True)
class BacktestFilterConfig:
    filter_new_listing: bool = True
    min_listing_age_calendar_days: int = 120
    filter_st: bool = True
    filter_suspended: bool = True
    force_delisting_liquidation: bool = True
    delisting_period_excluded: bool = True
    min_history_days: int = 20
    production_fidelity: bool = True
```

约束：

- 默认值必须全部开启，次新股阈值固定默认 120 个自然日。
- 参数只在回测启动前读取一次，运行中不可变更。
- `production_fidelity=True` 时禁止关闭核心规则；调试模式关闭规则后，结果必须带 `non_fidelity_reason`。
- 配置快照写入回测记录，配置 hash 写入净值和交易明细。

## 4. 四类标的规则

### 4.1 次新股

以历史时点的 `listing_date` 计算：

```text
listing_age = signal_date - listing_date
listing_age < 120 个自然日 => 不进入选股池，不允许新开仓
```

上市前无交易记录、上市日期未知或日期晚于信号日时，标记为 `listing_status_unknown`，正式回测阻断该股票日样本；不能默认为老股。

### 4.2 ST / *ST

使用逐日生效的证券状态，不使用当前名称回填历史。

- 信号日为 ST / *ST：从新开仓候选池剔除。
- 持仓在持有期间变为 ST：不强制平仓，保持持仓，直到正常调仓、退市清算或策略终止。
- 状态缺失：生产回测默认阻断该股票日样本并发出数据治理告警；只有明确选择“状态未知纳入”时才允许非保真实验。

### 4.3 停牌

- 信号日停牌：禁止新开仓和调仓。
- 已持仓且当日停牌：冻结仓位，不产生买卖成交，不虚构成交价和成交量。
- 目标收益的入场日或退出日不可交易：该股票日样本不进入真实收益统计，记录 `entry_not_tradable` 或 `exit_not_tradable`。
- 不允许用前一日收盘价模拟停牌成交。

### 4.4 退市

- 退市整理期：剔除新开仓池，已有持仓按策略规则处理；若交易所状态表定义为不可交易，则按停牌处理。
- 正式摘牌：以历史记录中的最后一个有效收盘价强制平仓，盈亏计入净值，记录 `delisting_liquidation`。
- 最后交易日无有效收盘价：不得用 0 或估算价，标记为 `delisting_price_missing` 并阻断该持仓净值结算，生成高优先级数据告警。
- 退市后的历史数据不得从行情和因子面板删除。

## 5. 固定每日执行链路

```text
加载 t 日 Point-in-Time 行情和证券状态
    -> 校验数据完整性和状态时效
    -> 按配置执行次新股 / ST / 停牌 / 退市整理期过滤
    -> 执行退市持仓强制清算
    -> 生成候选池
    -> 执行调仓（停牌持仓冻结）
    -> 计算成交、成本、净值和过滤审计
    -> 写入 t 日结果及证据
```

调仓计算不得先生成订单再回头过滤；过滤后的候选池、冻结持仓和清算订单必须进入同一事务或同一可重放事件序列。

## 6. 数据模型与数据契约

建议新增或补齐以下时效表。若数据源不能提供历史状态，接口返回 `unknown`，不得用当前快照替代。

### 6.1 `security_status_daily`

| 字段 | 含义 |
|---|---|
| `symbol` | 证券代码 |
| `trade_date` | 状态生效交易日 |
| `is_st` | 是否 ST |
| `is_suspended` | 是否停牌 |
| `is_delisting_period` | 是否退市整理期 |
| `is_listed` | 当日是否仍上市 |
| `listing_date` | 上市日期 |
| `delisting_date` | 正式摘牌日期 |
| `status_source` | 数据源 |
| `source_updated_at` | 源更新时间 |
| `as_of_batch_id` | 数据批次 |

### 6.2 `backtest_filter_events`

每条被过滤、冻结或清算的股票日记录一条事件：

```text
run_id, trade_date, symbol, action, rule_code, reason,
raw_status, effective_status, price_used, config_hash, data_batch_id
```

`action` 至少包括 `exclude_candidate`、`freeze_position`、`force_liquidate`、`include`。

### 6.3 预检返回

评测或回测启动前必须返回：

```json
{
  "requested_trade_days": 394,
  "usable_trade_days": 390,
  "minimum_trade_days": 300,
  "excluded_symbol_days": {
    "new_listing": 1200,
    "st": 380,
    "suspended": 760,
    "delisting_period": 14,
    "status_unknown": 0,
    "price_or_volume_invalid": 31
  },
  "target_coverage": {"covered_days": 390, "requested_days": 394},
  "warnings": [],
  "blocking_reasons": []
}
```

## 7. 缺失和异常数据治理

### 7.1 因子值

- `NaN`、`Inf`、分母为 0、价格小于等于 0：排除该股票日样本并记录原因。
- 统计有效率、有效交易日、有效股票数、异常率和按字段分布。
- 因子值可以按配置执行横截面 winsorize，但必须同时保留原始值、处理后值和阈值。

### 7.2 目标收益

- 目标标签缺失时只保留真实覆盖的标签日期，并提示缺口。
- 禁止使用因子自身变化冒充未来收益。
- 目标标签覆盖不足以满足时间切分最低要求时直接阻断，并显示实际值、最低值和缺口。
- 目标收益极端值只告警，不静默裁剪；若启用裁剪，必须在配置和报告中显示。

### 7.3 数据截止和时效

报告同时显示行情最新交易日、证券状态最新交易日、目标标签最新信号日和各自批次号。任一关键数据源超过时效阈值，评测不得显示为正常通过。

## 8. 指标与报告要求

报告必须区分以下三类数量：

1. 原始股票日数量；
2. 过滤后可交易股票日数量；
3. 实际进入 IC、分组收益和净值计算的有效样本数量。

门禁失败时必须显示“指标值 + 阈值 + 证据范围 + 排除统计 + 数据批次”。例如：

```text
Rank IC 均值 -0.6707（门槛 > 0）
真实目标覆盖 390/394 天
因子目标 fallback_used=false
停牌排除 760 个股票日，ST 排除 380 个股票日
```

不得出现“拒绝原因有数值、基础指标显示 `-`”的情况；后端嵌套指标和旧版扁平指标必须统一归一化展示。

## 9. 开关与实验治理

生产模式：

- 四类过滤全部开启；
- 禁止单独关闭后标记为正式回测；
- 回测报告显示 `production_fidelity=true`。

消融模式：

- 每次只能通过统一配置关闭规则；
- 报告显示关闭项、影响的股票日数量和与基线的差异；
- 不允许在代码中增加“某股票例外”“某日期例外”。

## 10. 验收标准

- 所有交易决策只读取历史时效数据，抽样审计不得发现未来状态。
- 新开仓中不存在信号日停牌、ST、上市未满 120 天或退市整理期股票。
- 停牌持仓当日无成交、无虚构价格，仓位状态可回查。
- 每个正式退市持仓均有最后有效收盘价清算事件；缺价时回测阻断并告警。
- 退市股票历史行情和因子值仍可查询。
- 预检能显示最小交易日、实际交易日、目标标签覆盖、各类排除数量和异常率。
- 关闭任一过滤开关后，结果被标记为非保真实验且配置 hash 改变。
- 同一数据批次、配置和代码版本重复运行结果一致。
- 单元测试、集成测试、历史事件回放和前端验收全部通过。
