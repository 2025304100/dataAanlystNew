## 1. 四层体系与必要修正

采用“分事件类型基准量化＋行业与指标口径校准＋定性规则修正＋样本迭代调优”的四层体系。

| 层次 | 解决的问题 | 首版执行方式 |
|---|---|---|
| 分类型量化 | 不同事件无法用一个比例衡量 | 五类事件分别定义指标、公式和五档锚点 |
| 行业校准 | 相同比例在不同行业的意义不同 | 根据利润率、弹性、库存、替代能力、周期和指标分布校准配置 |
| 定性修正 | 数字未覆盖执行机制或关键约束 | 只允许有依据、未在量化中计入的机制修正，最多一档 |
| 样本迭代 | 初始锚点可能不符合实际价值 | 先试算、再独立评测，达到验收条件后启用 |

对最初建议中的以下内容作出修正：

| 原建议 | 修正后的约定 | 原因 |
|---|---|---|
| 按行业产值大小直接应用 0.7 / 1.0 / 1.5 系数 | 不作为默认生产规则；系数默认 1，待验证后才可启用实验配置 | 行业占比已进行规模归一化；仅凭行业体量再次调整，可能造成二次偏置 |
| 无来源、无基线或未核验直接计 0 分 | 记录待核实状态，分数为 null | 未知不等于无影响 |
| 因发布机关层级高而强制升档 | 发布主体用于证据和执行机制核验，不能单独加分 | 高层级文件也可能只是原则性表态 |
| 因超预期升档、因提前吹风降档 | 交由新增变化维度处理，不重复调整实质影响 | 避免同一个事实重复计分；提前吹风也不能证明市场已消化 |
| 因持续时间、覆盖范围再次升降实质影响 | 实际影响量的测算可以使用时间和范围；不得再以相同事实机械升降档 | 上位方案已对影响范围与持续性单独计分 |
| 同比增速偏离使用百分比但未定义口径 | 增速差使用百分点，保留正负方向 | 增速之差与相对增幅含义不同，低基数和负增速下尤其容易失真 |
| 单一企业或地方事件一律最高 20 分 | 按其对目标市场的实际影响判断 | 单一关键供应商或核心产区也可能造成行业级冲击 |
| 新类型直接套最接近类型，满 20 条即形成标准 | 未支持类型进入复核；20 条只能作为探索起点 | 指标可能不兼容，样本数量也不能代替独立验证 |

以上修正保留分类型量化方向，同时防止参考标尺被误用为全行业通用标准。

## 2. 评分边界与事件分类

### 2.1 五类首版事件

| 类型代码 | 事件类型 | 主指标 |
|---|---|---|
| fiscal_support | 专项资金与财政支持 | 可比期间的新增净支持额占目标行业规模的比例 |
| supply_disruption | 限产与供给中断 | 相同期间、相同产品市场的净可用供给缺口比例 |
| demand_change | 行业需求变化 | 可比需求增速偏离有效历史基线的百分点数 |
| cost_change | 成本变动 | 计入对冲与价格传导后的净经营影响额占基线营业成本的比例 |
| regulation_access | 监管与准入变化 | 实际业务约束、合规义务和准入变化的已审核规则 |

上述五类不能覆盖所有宏观事件。利率、准备金、汇率制度等需要独立的指标与传导模板；尚未建立模板时标记 unsupported_type，进入人工复核，不能直接套用财政支持比例。

一条消息包含多个事件时先拆分事实；同一事实涉及多个类型时记录类型关系，不将多个实质影响分数相加。主事件与相关事件的选择需要留有理由。

### 2.2 与其他评分维度的分工

| 信息 | 本维度如何使用 | 避免的重复计分 |
|---|---|---|
| 新旧条款、存量与增量 | 确定此次变化实际改变的经济变量 | 新颖性再由“新增变化”计分 |
| 执行状态 | 区分计划额度、已批准额度和实际执行量 | 不因“正式发布”同时在多个规则中连续升档 |
| 影响期间 | 计算同一期间的净资金、净供给或净成本变化 | 不因“持续一年”再额外升一档 |
| 目标范围 | 确定正确的分母与适用市场 | 不再因“全国性”机械升档 |
| 超预期或提前预告 | 记录可核验的预期材料 | 不据此调整实质影响，避免与新增变化重复 |
| 发布主体 | 核验来源及执行权限 | 不将主体级别等同于经济影响大小 |

## 3. 状态、计算顺序与拦截条件

### 3.1 评估状态

| 状态 | 含义 | 实质影响分数 | 自动提醒资格 |
|---|---|---|---|
| scored | 依据与口径满足要求，完成评估 | 0 / 10 / 20 / 30 / 40 | 还须通过配置验证状态及上位方案全部门槛 |
| insufficient_evidence | 关键事实或原文不能核验 | null | 无 |
| baseline_unavailable | 缺少必要基线或基线不适用于事件时点 | null | 无 |
| baseline_mismatch | 行业、地域、期间、单位等口径不匹配 | null | 无 |
| unsupported_type | 尚无可适用的事件模板 | null | 无 |
| review_required | 来源冲突、结果区间跨档、定性机制未形成规则等 | null；可记录诊断性试算区间 | 无 |

证据充分且确实没有相关经济变化时，才能计 0 分。纯传闻、缺少金额或基线不清时不得为了填满五档而计 0 分。

### 3.2 计算顺序

1. 识别事件类型、目标行业或产品市场、地域、方向和影响期间。
2. 核验原始事实、发布时间及关键数据来源。
3. 选择事件评估时点之前已经可获得、口径匹配的基线版本。
4. 选择类型与行业匹配的规则配置，检查其版本和验证状态。
5. 将输入统一为可比金额、产量、期间和单位，计算主指标。
6. 按互斥区间得到基础档位。
7. 应用未重复计入的定性修正；发生冲突时进入复核。
8. 保存公式、输入快照、引用、命中区间、修正记录及最终状态。
9. 只有状态与配置均满足条件，才将本维度分数交给总分与提醒判断。

### 3.3 不确定性

已知上下界时保留区间，不允许只挑最有利于提高分数的一端。区间跨越评分档位时进入复核；若整段区间落在同一档位，可记录上下界和依据后按该档处理。

分母为 0、负值、单位未识别、关键数据冲突或金额无法拆分到目标行业时，拦截计算，不自动替换为默认数值。

## 4. 行业基线、单位与时间口径

### 4.1 基线要求

基线来源优先采用统计部门、主管部门、行业协会及公开披露的可核验数据。企业披露可以支持企业事实或有依据的样本估计，但不能自动扩展成全行业总量。

| 校验项 | 要求 |
|---|---|
| 行业分类 | 保存分类体系、版本和行业层级；申万行业与统计行业映射需要审核 |
| 产品范围 | 区分细分产品市场与整个上级行业，禁止为提高比例而临时缩小分母 |
| 地域 | 地方分子匹配地方目标市场；全国分母只能用于确实评估全国影响的场景 |
| 期间 | 明确月、季、年或指定窗口；多年度金额不得直接除以单年度规模 |
| 指标 | 产值、营业收入、增加值、产能、产量分别管理，不互相隐式替代 |
| 样本覆盖 | 记录规上企业、全行业或协会样本等覆盖范围 |
| 可获得时间 | 基线发布时间必须不晚于评估时点，防止历史评测使用未来资料 |
| 修订 | 新旧版本均保留，历史评估引用原版本，不被事后修订覆盖 |
| 新鲜度 | 按指标发布频率配置复核周期；旧数据是否可用需显式确认 |

工业总产值和营业收入的计算依据不同，不能简单互换；指标配置必须明确选用哪一种分母。[国家统计局：什么是工业总产值](https://www.stats.gov.cn/zs/tjws/jbtjzswd/tjzb/202503/t20250320_1959105.html)

### 4.2 数值约定

- 比例在字段中按小数保存，例如 2.8% 保存为 0.028；展示时转换成百分比。
- 增速差按百分点保存，例如从 5% 到 8% 的差为 3 个百分点，保存为 3.0。
- 金额记录币种和单位，换算使用明确汇率及其时点。
- 方向与强度分离：先保留带符号的变化，再按绝对强度匹配档位。
- 确定性计算使用十进制定点数，边界比较前不做展示性四舍五入。

百分比与百分点含义不同，增速之差应使用百分点表达。[国家统计局：“百分数”与“百分点”](https://www.stats.gov.cn/zs/tjws/tjbk/202301/t20230101_1912934.html)

## 5. 五类事件的指标与试算锚点

本节阈值仅是未校准的模板。表内区间采用左闭右开约定；0 为单独情况。边界值落入较高一档，例如财政比例恰为 2% 时，基础档位为 30 分。

### 5.1 专项资金与财政支持

#### 指标与公式

```text
ΔB_H = 相比旧安排，在期间 H 新增的可核验净支持额
S_H  = 同范围、可比期间的行业规模基线
r_fiscal = abs(ΔB_H) / S_H
```

配置必须指定分母为产值、营业收入或其他已验证的规模指标，不可在一次评分中混用。评估未来期间时，可以使用已发布的最近可比基线，但须说明期间差异和适用性，不能把预测值标成已实现数据。

| 基础分 | 比例 r_fiscal 的试算区间 | 必需说明 |
|---|---|---|
| 0 | 经核验 ΔB_H = 0，且不存在独立的实质条款变化 | 纯重复、无新增支持的表态；延续政策是否改变原定到期安排需另行核验 |
| 10 | 0 < r_fiscal < 0.5% | 可核验的新增净支持，规模较小 |
| 20 | 0.5% ≤ r_fiscal < 2% | 按正确期间与目标范围计算 |
| 30 | 2% ≤ r_fiscal < 5% | 资金性质、执行条件和传导路径可核验 |
| 40 | r_fiscal ≥ 5% | 同上，且高比例不是由错误分母或多年金额造成 |

计算约束：

- 贷款、授信、担保、基金目标规模不能直接视为净补贴额。贴息以可核验的利息减免额计算，税收优惠以对应期间的实际或依法可确定让利额计算。
- 三年总额仅在年度安排已明确时按年度拆分；不能默认平均分三年，也不能将三年总额直接与一年行业规模比较。
- 计划额度、正式承诺和实际拨付分别记录。条件尚未满足且可能改变结论时进入复核。
- 政策延续可能避免原定退出或到期，需要依据原安排确定反事实，不能一律判为零新增。
- 一次性补贴不自动降档；其金额按适当期间计算，持续性由独立维度处理。
- 单一企业支持不自动封顶 20 分，需核实其对目标行业的代表性及传导机制。

### 5.2 限产与供给中断

#### 指标与公式

```text
Q_cf_H   = 若无本次事件，期间 H 的可比市场可用供给量
ΔQ_loss  = 本次事件导致的有效供给损失量
Q_sub    = 相比无事件基线，新增且可交付的替代供给量
Q_buffer = 期间 H 内可额外释放的可用库存量
Q_gap    = max(0, ΔQ_loss - Q_sub - Q_buffer)
r_supply = Q_gap / Q_cf_H
```

名义产能受限占比作为辅助信息。主指标使用同一期间的净供给量，避免把产能存量、年产能速率和一个月损失量混除。每一项替代供给和库存缓冲只计入一次。

| 基础分 | 比例 r_supply 的试算区间 | 必需说明 |
|---|---|---|
| 0 | 经核验所选期间无净供给缺口，且未发现其他独立影响机制 | 倡议本身不是零分充分条件，仍需核验实际供给 |
| 10 | 0 < r_supply < 3% | 有限的净供给缺口 |
| 20 | 3% ≤ r_supply < 10% | 已计入可核验的进口、替代和库存缓冲 |
| 30 | 10% ≤ r_supply < 20% | 有效损失、期间、恢复条件及缓冲有依据 |
| 40 | r_supply ≥ 20% | 同上，且评估口径不夸大名义产能影响 |

计算约束：

- 停产设备原本闲置时，不能按全部名义产能计算损失。
- 进口或替代供给必须考虑实际到货时间、运输与认证约束。
- 库存必须可用、可释放并匹配期间，不能把全部库存假定立即可用。
- 库存或替代量未知且影响跨档时，保留区间并进入复核。
- 库存、替代供给已在净缺口中扣除后，不再据此额外降一档。
- 上游关键环节不自动升档；需要证明下游不可替代或其他未计入的约束机制。

### 5.3 行业需求变化

#### 指标与公式

```text
g_t = 同口径需求量或需求金额的当期可比增速（百分数）
b_t = 已定义方法形成的可比增速基线（百分数）
d_demand_pp = abs(g_t - b_t)（百分点）
```

当期增速与基线之差使用百分点，不能再除以接近零或为负的历史增速。需求方向单独记录。同比增速、环比增速、季调环比和累计同比不得混用。

| 基础分 | 偏离 d_demand_pp 的试算区间 | 必需说明 |
|---|---|---|
| 0 | 经核验无异常变化，属于配置中定义且已验证的正常波动 | 正常波动区间须有基线；无基线不计零分 |
| 10 | 0 < d_demand_pp < 5 个百分点 | 存在可比变化，尚未达到更高模板边界 |
| 20 | 5 ≤ d_demand_pp < 15 个百分点 | 数据口径一致，已检查低基数和季节性 |
| 30 | 15 ≤ d_demand_pp < 30 个百分点 | 有可信数据与机制解释，证据符合该指标配置 |
| 40 | d_demand_pp ≥ 30 个百分点 | 同上，排除统计口径变化等造成的虚假偏离 |

计算约束：

- “近三年同期”仅有少量年度同月样本，不能直接当成稳定统计分布。基线方法、样本长度和结构变化处理须写入配置。
- 高波动行业与低波动行业分别校准阈值；未校准模板仅试算，不参与自动提醒。
- 单月、连续两月或三月的证据分别记录。不能一律等到连续三个月才识别首次强变化，也不能仅凭一个月就宣称形成趋势。
- 连续月份用于趋势验证和持续性判断，不机械升降实质影响。
- 季节性、价格因素、样本扩容及基数效应需要明确处理；名义金额变化不能直接等同于实际需求量变化。
- 龙头企业订单是否代表行业，需要可核验的市场份额、产品和地域匹配，不能仅凭“龙头”称谓升档。

若配置存在已验证的正常波动区间，优先执行其零分规则；其余区间须随该配置一起校准并校验互斥性。

### 5.4 成本变动

#### 指标与公式

```text
C0_H = 同期间、同产销口径的基线营业成本
ΔC_H = 考虑采购合同、套保与库存计价滞后后的有效成本变化额
ΔR_H = 有证据支持、因成本传导带来的收入变化额
ΔP_H = ΔR_H - ΔC_H
r_cost = abs(ΔP_H) / C0_H
```

该公式是固定其他条件下的局部经营影响估计，不能冒充完整利润预测。若成本变化伴随明显销量变化，需建立有依据的联合情景或拆出需求事件，不能继续假设销量恒定。

| 基础分 | 比例 r_cost 的试算区间 | 必需说明 |
|---|---|---|
| 0 | 经核验本经营环节净影响为 0，且没有其他独立影响机制 | 不代表产业链其他环节无影响 |
| 10 | 0 < r_cost < 2% | 已核验成本权重及实际传导 |
| 20 | 2% ≤ r_cost < 5% | 同上，具有可比期间和经营范围 |
| 30 | 5% ≤ r_cost < 10% | 净影响明确，利润敏感性与传导路径可解释 |
| 40 | r_cost ≥ 10% | 同上，排除仅用原材料报价推算全行业成本的误差 |

计算约束：

- 原材料涨幅不等于营业成本涨幅。需要原材料在营业成本中的权重、用量和有效采购成本变化。
- 价格传导与套保已计入净影响后，不再据此降一档。
- 不将成本变动占比直接等同于利润率变化百分点。利润率需分别根据收入、成本和价格变化计算。
- 薄利行业可能对较小成本变化高度敏感，应通过已验证的行业配置和利润敏感性指标处理。
- 完全传导可能影响下游需求、回款或现金占用，不能据此宣称整条产业链无影响。
- 对成本下降使用相同强度口径，方向单独判断。

### 5.5 监管与准入变化

法律效力层级作为元数据保留，基础分由实际新增业务约束决定，不能使用“法律必为 40 分、部门文件必为 20 分”的映射。

| 基础分 | 可审核的机制锚点 | 必须核验的依据 |
|---|---|---|
| 0 | 已核实无新增义务、准入变化或执行变化的重复或原则性表态 | 新旧条款对照及无新增机制的理由 |
| 10 | 轻微、局部的披露或流程变化 | 适用对象、具体条款和较小经营影响 |
| 20 | 明确新增合规或经营要求，但尚未显著改变准入和核心业务 | 可执行义务、期限和影响路径 |
| 30 | 显著改变准入、许可、业务可行性或合规成本 | 具体限制、执行依据及目标市场影响证据 |
| 40 | 对目标市场关键业务形成禁止、退出或根本性重构约束 | 生效状态、替代路径和关键业务不可持续的证据 |

执行要求：

- 30 / 40 分需要命中经过审核的机制规则及其必需证据字段，不能让模型仅凭措辞生成等级。
- 征求意见稿记录为 draft，不视为生效约束；原则上进入观察或复核，不能简单减一档后就自动提醒。
- 没有新增处罚条款不代表没有影响；文件也可能依据既有法律义务执行。
- 没有文号不代表事实必假，不能仅凭文号有无判零分；应核验正式发布渠道和可执行事实。
- 过渡期、地域与覆盖范围分别记录，不按长短或行政层级自动升降档。

行政规范性文件、部门规章与行政法规属于不同文件类别；具体约束和制定权限需要核验原文。公开文件也可能具有普遍约束力，不能简单将规范性文件等同于“没有约束”。[国务院办公厅关于加强行政规范性文件制定和监督管理工作的通知](https://app.www.gov.cn/govdata/gov/201805/31/425127/article.html)

## 6. 行业校准机制

### 6.1 不默认使用体量系数

同一比例在不同行业的后果可能不同，但仅凭行业绝对产值大小，无法推出应采用 0.7 或 1.5 的系数。利润率、价格弹性、库存、资本强度、替代性、集中度和政策可执行性更接近实际传导机制。

首版约定：

| 参数 | 默认值或状态 |
|---|---|
| 行业规模系数 | 1.0 |
| 类型模板验证状态 | unvalidated，仅试算 |
| 行业专属阈值 | 由已标注样本形成候选配置，验证后启用 |
| 未匹配行业 | 可以按通用类型模板试算，自动提醒资格为 false |
| 行业分类映射不明确 | baseline_mismatch，等待审核 |

优先对实际关注最多的 5—8 个行业建立指标配置。某个行业只有少量样本时，不强行形成五档完整标准。

### 6.2 可选系数实验的数学约定

确需试验统一系数时，必须先定义其含义：

```text
T_industry = T_type / k
```

其中 T_type 为类型模板边界，k 为已验证的行业灵敏度参数。

- k = 0.7 时，2% 边界变为约 2.857%，意味着更难触发，不应称为放宽。
- k = 1.5 时，2% 边界变为约 1.333%，意味着更容易触发。
- 系数不能仅由产值分档生成，且不能同时调整指标与边界。
- 单个系数未必能合理缩放所有档位，可采用独立行业阈值向量；两种方式不得叠加使用。

只有独立样本证明改进且未造成不可接受漏报时，才启用该配置。上述 k 数值仅用于解释公式，不是生产默认参数。

## 7. 定性修正与冲突处理

### 7.1 可修正与不可修正的内容

| 情况 | 处理 |
|---|---|
| 发现未计入指标的额外强约束机制 | 只有命中已审核规则、具备证据且未重复计分时，最多升一档 |
| 发现未计入指标的缓冲或限制机制 | 优先重新计算指标；无法直接计量但符合已审核规则时，最多降一档 |
| 缺少来源、基线或关键数据 | 调整状态为待核实或复核，不能通过降档代替 |
| 已在净额、净缺口或净成本中扣除的因素 | 不再降档 |
| 发布机关层级、转载数量、标题措辞 | 不作为升降档依据 |
| 市场预期、影响范围或持续时间 | 按上位方案相应维度处理，不重复升降档 |

### 7.2 档位合并规则

```text
final_score = clamp(base_score + adjustment_steps × 10, 0, 40)
adjustment_steps ∈ {-1, 0, 1}
```

- 多条同方向规则只修正一次，不连续累计。
- 升档与降档同时命中时进入 review_required，不自动选择更高结果。
- 基础分为 0 时，若新增证据表明存在重要机制，应重新评估类型与基础分，不能靠一般修正规则升档。
- 升到 30 / 40 分仍须满足该类高档位的证据要求。
- 每次修正保存 rule_id、证据及“为何未在其他字段计入”的说明。

## 9. 复算示例

本节所有行业、金额与结果均为假设数据，仅用于说明公式，不是官方统计或真实政策案例。真实评分必须附带实际来源与基线版本。

| 示例 | 输入与计算 | 试算结果 |
|---|---|---|
| 单年度净支持 | 新增净支持 140 亿元，可比年度行业规模 5000 亿元；140 / 5000 = 2.8% | 财政模板基础分 30，仍需检查配置与证据 |
| 多年度资金 | 三年总额 150 亿元，原文明确每年 50 亿元；年度行业规模 5000 亿元 | 年度比例 1%，财政模板基础分 20；不能按 3% 得 30 |
| 多年度拆分未知 | 同为三年 150 亿元，但未说明年度安排 | 不能假设均摊；按待核实或已证实区间处理 |
| 产能与净供给不同 | 窗口内无事件供给 100 单位，损失 20，新增替代 12，可释放库存 6 | 净缺口 2 / 100 = 2%，供给模板基础分 10 |
| 增速差 | 当期增速 8%，有效基线 5% | 偏离 3 个百分点，需求模板基础分 10；不是偏离 60% |
| 净成本影响 | 基线营业成本 100，成本增加 6，对应有依据的收入增加 4 | 净经营影响绝对值 2，比例 2%，成本模板基础分 20 |
| 来源不明 | 宣称新增补贴但找不到可核验原文 | insufficient_evidence，final_score = null，不能计 0 |
| 原文重复 | 同一政策被再次报道，关键事实没有变化 | 复用事件既有评估，新增变化不足，不重复提醒 |

模板试算得到 30 / 40 分，不等于具备主动提醒资格；未验证的模板始终 auto_alert_eligible = false。

## 10. 样本校准与启用流程

### 10.1 第一阶段：基线与只评分试运行

1. 优先建立重点行业与指标的基线清单，确认数据可得性和映射。
2. 加载五类试算模板，默认只评分，所有自动提醒开关关闭。
3. 输出量化指标、分子分母、期间、数据来源、配置版本和修正理由。
4. 未支持的宏观类型进入复核，统计遗漏，不隐式套用其他类型。

### 10.2 第二阶段：样本标注与独立评测

1. 以 100—200 个独立事件作为起步集，按事件类型、行业与边界案例检查覆盖情况。
2. 试运行 1—2 个月作为观察安排，实际启用取决于证据与评测结果，不能仅因时间到期自动上线。
3. 保留较新事件作为独立测试集；同一事件及其转载不跨组。
4. 标注时先形成业务价值判断，再复核口径与档位，避免只检验规则能否复现自身。
5. 分析相邻档位误差、高估低估、资料不足率、重要事件遗漏与提醒有用率。
6. 只对样本支持且验证通过的类型与行业启用配置。100—200 条不能保证覆盖所有行业与五档组合。

### 10.3 第三阶段：受控启用与持续复核

- 通过后形成 V1.0 配置，保存参数变更、样本范围、独立评测及审核记录。
- 自动提醒继续通过上位方案的总分、分项、证据、去重和每日额度门槛。
- 季度进行基线及固定样本复核；出现明显评分漂移、政策机制变化或数据修订时及时复核。
- 新类型先进入只评分或人工复核，不按样本数量自动转为生产规则。
- 规则或模型升级不改变事件事实版本，不能因此重新提醒历史事件。

下表为后续实现应覆盖的用例设计，本轮文档工作不代表已执行评分程序测试。

| MI-17 | 增速基线接近零或为负 | 不用增速相除方式计算偏离 |
| MI-18 | 需求单月异常或统计口径变化 | 不自动认定趋势；检查基数与可比性 |

| MI-22 | 较低层级但已有强业务约束 | 按执行机制与已审核规则判断，不按层级封顶 |
| MI-23 | 征求意见稿与正式生效文件 | 状态及约束分离，草案不视为生效 |

| MI-25 | 升档与降档同时命中 | review_required，不自动取高分 |
| MI-26 | 测算上下界跨档 | review_required，保留区间 |
| MI-27 | 类型模板未校准但试算达到 40 分 | 可展示试算，自动提醒资格为 false |
| MI-28 | 行业缺少验证配置 | 仅试算，不回退为通用生产阈值 |
| MI-29 | 未支持的利率或准备金事件 | unsupported_type，记录复核与遗漏 |
| MI-30 | 规则版本更新、事件事实未变 | 不重复提醒，不改写历史评估 |
| MI-31 | 人工将资料不足与无影响混淆 | 标签校验与复核明确区分两者 |
| MI-32 | 政策延续避免原定到期退出 | 按原安排反事实核验，不一律计 0 |
| MI-33 | 负向资金或成本改善事件 | 强度按绝对值计算，方向单独保留 |
| MI-34 | 单一关键企业或地方核心产区事件 | 不自动封顶 20 分，按目标市场影响核验 |

回归还须覆盖总分 85 分、实质影响 30 分、新增变化 20 分和每日额度的联合判断，避免本维度合格即直接发送通知。

| 风险 | 必须检查的内容 |
|---|---|
| 表面量化造成虚假精确 | 阈值是否经过独立验证，试算与生产状态是否清晰区分 |
| 错分母放大或缩小影响 | 行业、产品、地域、期间与指标口径是否匹配 |
| 机械系数二次偏置 | 是否已归一化，行业调整是否有样本支持 |
| 多维度重复计分 | 执行、时效、覆盖、持续性和新增变化是否各自归位 |
| 稀疏样本误判已校准 | 是否披露类型、行业及档位覆盖，未验证配置是否保持关闭 |
| 严格规则造成重要漏报 | 是否统计资料不足与未支持宏观类型，是否有复核入口 |
| 事后数据污染评测 | 是否保存公开时间、基线版本与评估时点 |
| 行情反应误当经济影响 | 是否分开事实、经营传导与事后价格变化 |

本细则的生产启用条件是“数据口径可核验、配置有验证依据、异常可拦截、结果可复算、提醒价值达到验收要求”，不以评分表已经填满作为完成标准。
