|---|---|
| 运行的后端连接 MySQL `127.0.0.1:3306/gpfx`（非 SQLite） | `init_db Failed to seed factor definitions: (1054, "Unknown column 'factors.origin' in 'field list'")` — **生产 MySQL 未应用最新迁移（缺少 origin / lifecycle_status 等新列）**。⚠️ 但不影响黑盒测试（其另一部分用 TestClient 自带 SQLite 隔离） |

| 404 响应协议差异 | 部分路由走 `UnifiedError`（无 `detail` 字段）、测试断言 `detail`；全局统一即可 |

## 6. 风险与后续建议

### 6.1 立即执行（进入 R3 模型接线正式生产前）

1. **生产 MySQL 执行 Alembic 全量迁移**，确保 `factors.origin`、`lifecycle_status`、`factor_versions`、`factor_evaluation_runs` 等 24 个 revision 全部到位；当前运行的 MySQL 实例未应用最新迁移导致 seed 失败告警。
2. **修复黑盒 404 协议断言一致性**：UnifiedError 无 `detail` 字段 → 更新 3 个测试用 `user_message`/`error_code` 断言。
3. **ObservationPool / ExcludedPool 的 i18n mock 补齐 `enumLabel` 导出**：修复 11 个前端失败（仅 2 个测试文件）。
