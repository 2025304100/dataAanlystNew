2. 整体判断

一句话结论

方向值得做，但当前是"工程能力严重过剩、产品闭环没有闭合"的状态——核心赌注是用工程化手段解决个人投资者"决策不可信、复盘无纪律"的痛点，赌注成立，但兑现前提是把断掉的链路补上；以当前状态上线，留不住任何一类用户。

核心链路（数据 → 因子 → 评分 → 机会 → 组合 → 回测）中成熟度最高的是组合交易与机会中心，最差的是因子挖掘 v2（骨架，主链路 4 个 P0 走不通）。这是系统性错位而非普通延期：后端能力大量就绪（preview 返回真实数据、filter-fields 返回 19 个字段、import-template 返回 CSV 模板），前端 UI 根本没有接入——71 个后端方法、72 个前端 API 封装、104 条前端未使用诊断并存，"后端 4,021 个函数 / 516 个路由"的引擎配的却是一批"点了不干活、没有任何反馈"的按钮。

2.1 目标用户画得准不准

画得不准。 可用性方案写"不熟悉量化的普通投资者，同时兼容专业用户"——这是最典型的定位摇摆。A 股真实分层：约 90% 用户在同花顺/东财看行情加自选，约 5% 用 i问财/条件选股，真正碰因子、评分、回测的不足 2%。普通投资者看到 "Quality Score / Timing Score / Z-Score" 就跑；专业用户又嫌 AntD 套壳不够深。两头都要 = 两头都不要。

2.2 痛点真伪

有真有假。 真痛点：决策可信度（"行情过期了系统还让我买"）、数据时效（85.7% 标的行情过期）、复盘纪律（"买了不知道当时为什么买，复盘全靠拍脑袋"）。伪需求："自动进化挖掘因子"——个人投资者没有跑遗传算法的场景，这是为做而做的自嗨功能，还恰好占着 4 个 P0。

2.3 差异化

不存在于功能清单里。 行情打不过同花顺/东财（AkShare 免费数据更差），回测打不过聚宽/米筐。唯一像壁垒的资产是证据链 + 快照哈希 + PIT mode + G0–G7 治理——但那是工程资产，用户感知不到，短期也换不来留存。

3. 优点（做多逻辑）

  1. 四层测试 + CI + pre-commit（约 550 用例），同类个人项目里罕见的工程纪律——对的，坚持。
  2. 证据链、快照哈希、PIT mode、版本追溯设计是专业级的，方向完全正确：金融工具的决策推荐必须可追溯，这是可信度底座。
  3. 组合治理 G0–G7 双跑门禁（快照冻结、双引擎对比、守恒校验），同类产品几乎没有。
  4. 不接券商、只做计划 + 记录成交的定位决策非常对：避开合规大雷，同时覆盖"决策辅助"真实场景。
  5. 技术选型务实：SQLite 默认、AkShare 免费源、FastAPI + React，没有为不存在的规模上重型基建。
  6. UI 深色主题、AntD 组件统一，专业感在线（回测中心截图观感良好）。

4. 缺陷与风险（做空逻辑）

4.1 产品层面

  • 核心路径硬伤（因子挖掘 4 个 P0，证据见 §9）：
    • P0-1 Step1 建池请求 405（URL 双斜杠空 id，MiningShell.tsx:314 未传 poolId）；
    • P0-2 Step3 无任何字段可选（fields 靠 props 注入、默认为 []，没人调用已就绪的 filter-fields 接口）；
    • P0-3 Step4 确认提交无请求、弹窗不关（MiningShell.tsx:206-211 因快照 id 恒空直接 return，且 onConfirm 不先关弹窗）；
    • P0-4 预览统计恒为空且"<50 硬阻断"失效（前端字段 total/matched/excluded 与后端 universe_size/hits/excluded_total 不匹配，undefined < 50 恒 false）。
  • 单测 834 例全绿、真实链路全断：测试全部用 mock 数据注入 props，真实渲染时无人注入——这是"自我安慰型"测试架构，比没测试更危险。
  • 自嗨功能：因子挖掘 v2（进化算法）、模板库初始为空且要手动"重置系统模板"才可用、Step4 参数"看得见填不进"（ClassicalBaseConfig / SelectionConfig 无 props、onChange 未接）。
  • 半成品状态直接暴露给用户：首页常驻"新买单暂不可用"、缺失 K 线、因子覆盖率 0%——这些本应是受控内部状态，却成了首屏事故现场。

4.2 商业层面

没有付费理由。 单机 + 免费数据源 + 无行情差异化，用户用脚投票会留在同花顺。获客无渠道（无社区、无内容、无导流）；留存取决于数据新鲜度（当前 85.7% 标的行情过期）。天花板：个人工具，零收入预期；若做 B 端研究工具则当前形态要重做。

4.3 竞争层面

同花顺不需要抄"证据链"——它抄走的是"能用"，用户要的也是"能用"。本项目活下来的唯一理由：场景足够小众（个人量化决策纪律），大厂看不上；一旦做大了，东财一个自选股界面就能吸走 90% 用户。

4.4 合规层面

当前"模拟交易 + 线下成交记录"模式安全。雷区在商业化那一步：

  • 对外收费提供评分/买卖建议 → 涉证券投资咨询业务资质（证监会监管红线）；
  • AkShare 实质抓取东财等网页接口 → 商业使用有数据来源合规与反爬风险；
  • R5 已证实数据库配置写接口无认证（STRICT_AUTH=1 下无凭据请求仍进入写处理器）——本地单机问题不大，一旦对外部署就是事故。

5. 架构设计意见

  • 选型匹配当前阶段，不过度设计。 但 54+ 个 Alembic 迁移、旧 init_db 双轨 schema 并存、DuckDB 多连接冲突（P1-2/P1-3 根因）说明数据层管理已开始失控，是最该还的技术债。
  • 4 个已复现的 P1 必须排最前（证据见 §9）：
    • R1 静态资源路径穿越（app/main.py:906 只检查 exists() 未解析路径，/assets/..%2f.. 可越界读文件）；
    • R2 数据库热切换后控制面仍连旧库（app/db/manager.py:41 更换主引擎未失效 _cp_factory，业务数据分裂）；
    • R3 数据库配置校验失败前已写盘（app/api/routes/db_config.py:82 先 save_db_config 后校验，400 不撤销磁盘写入）；
    • R4 取消超时巡检未接生产入口（app/services/async_tasks.py:835 能力已实现，生产 _run_patrol() 不调用，任务可假死）；
    • R6 模拟下单缺组合级并发串行化（app/services/sim_accounts.py 读改写无 FOR UPDATE，需 MySQL 并发实验验证）。
  • 实时行情：当前拉取/定时任务模式，未做 WebSocket 推送。对当前定位（盘后决策）是对的——但 UI 层缺断线重连、心跳、降级状态，要补。
  • 扩展性：SQLite 单机撑不住用户量 ×10，但当前阶段不需要。真正的瓶颈不在架构，在数据源：AkShare 免费接口限流 + 字段漂移（85.7% 行情过期即证据）。
  • 成本结构：服务器几乎零成本；行情数据授权（Level-1 全市场）是百万级年费，免费接口永远无法作为商业基础。数据新鲜度是产品命脉，应把"全量重拉"改为"增量同步 + 标的级水位 + 批次缓存"（方案 §24 已设计：ETF 全市场接口每批一次，可省约 90% 请求量）。

6. 交互设计意见

  • 核心路径步数：组合交易 5 子页、机会中心 4 子页结构尚可；但"机会 → 交易计划"没有闭合（计划向导仅在设计方案中，未落地）。高频用户需要的快捷键、批量操作、右键菜单、多窗口分屏、全局搜索——未见任何证据。A 股盯盘用户是"3 秒切窗口、5 秒看持仓"的动物，没有快捷键的 PC 工具会被认为"不够专业"。
  • 信息架构：6 个一级 Tab + 设置 18 个导航项，普通用户 3 步内找不到"数据镜像"或"公式与计划"。方案中的五入口 + 高级设置折叠是对的，但至今未落地。无 react-router、靠 ?tab= 深链接，多窗口对照场景完全没考虑。
  • 状态覆盖（最差的板块）：加载态（回测预检无限转圈 P1-3）、空态（Step3 空白无提示）、报错（英文底层错误直接甩用户 P1-2）、静默失效（预检/导入/保存暂存等 10+ 处）。方案 §12 的"错误四要素 + 恢复动作"与 §10 决策就绪状态，在验收时点未生效。断线重连无证据。
  • 移动端：当前组件全是桌面向（表格、抽屉、多列），移动端复用率估计 <30%，K 线与持仓表必须重做；但"决策就绪 / 普通语言解释 / 状态机"等逻辑层可复用。

7. 前端 UI 意见

  • 视觉一致性：AntD 深色主题统一，专业感达标；但 P2-6 用 <pre>{JSON.stringify(...)}</pre> 直接打印分析数据，暴露未完成态。
  • 信息密度：回测中心截图（参数左栏 / 快照右栏 / 净值曲线）是合格的金融密度；首页则信息过杂——"发现池维护 / 因子模型 / 优先机会 / 重要消息"四卡片主题不一。
  • 涨跌色：截图未见明显错误，但需显式核查：AntD 默认无红涨绿跌语义，若未全局配置就是事故级问题。
  • 响应式：无证据覆盖 2K / 4K / 带鱼屏；设计稿 HTML 固定宽度，风险高。暗色模式是刚需，当前已深色，OK。动效未见花哨，保持克制即可。
