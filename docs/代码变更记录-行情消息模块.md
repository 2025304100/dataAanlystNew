  - **回滚总原则**：代码回滚 → `alembic downgrade -1`（0086 的 downgrade 会删列删索引，回填的 hash 数据允许随列丢弃，不承载业务语义）→ 前端回滚后旧版页面仍按旧口径（本地聚合）工作，无数据依赖。**清理任务删除的行不可由 downgrade 恢复**，故清理任务默认 enabled 但删除条件带四重保护（见 P0-1），回滚前请确认已备份或接受删除。
