# 受控量化公式 DSL 因子编辑器开发计划

| 项目 | 内容 |
|---|---|
| 文档版本 | V1.0 |
| 编制日期 | 2026-08-14 |
| 适用项目 | Personal Quant Workbench / dataAanlystNew |
| 依据文档 | 《受控量化公式DSL因子编辑器最终改造方案》 |
| 交付目标 | 在现有因子中心中交付可编写复杂公式、可实时校验、可预览、可版本追踪的专业因子编辑器 |
| 实施原则 | 增量改造、后端契约先行、旧因子可回退、每阶段可独立验收 |

---

## 1. 交付范围

### 必须交付

- 受控量化公式 DSL Parser/Normalizer。
- 字段和函数目录统一 API。
- 数学、时间序列、条件、逻辑和首批常用量化函数。
- 函数辅助模式和高级表达式模式。
- 自动补全、参数提示、悬浮说明、行内错误定位。
- 公式校验、依赖分析、回看窗口和数据覆盖率诊断。
- 小样本预览和后处理配置。
- FactorVersion 的 DSL/AST/依赖/执行计划版本冻结。
- Candidate → Testing → Shadow → Active 生命周期接入。

### 本期不交付

- 任意 JavaScript/Python 运行时。
- 遗传编程、表达式树搜索和强化学习挖掘。
- 分钟级、高频或自动下单能力。
- 新的数据基础设施或新的外部数据供应商。

## 4. P0：编译契约和后端基础

### P0-A：DSL 规范冻结

**任务**

- 定义词法：标识符、数字、字符串、括号和逗号。
- 定义运算符：`+ - * / % **`、比较、`&&`、`||`、`!`。
- 定义条件：`if(condition, a, b)` 和三元表达式。
- 定义类型：`number`、`boolean`、`series`、`window`、`string`。
- 定义空值、除零、非法 `log`、非法 `sqrt` 和异常值语义。
- 定义 DSL 版本和兼容策略。

**交付物**

- DSL 语法说明。
- 合法/非法样例集。
- 类型和缺失值行为表。

**验收**

- 所有示例能够明确归类为合法或非法。
- 前端、后端和测试使用同一套语法约定。

### P0-B：Parser/Normalizer

**任务**

- 新增 JS-like DSL 解析器，禁止任意代码执行。
- 将 `&&`、`||`、`!`、三元表达式转换为规范 AST。
- 输出字符位置映射，支持前端行内错误标记。
- 接入现有 `factor_compiler` 白名单和复杂度校验。
- 保留旧公式兼容路径，旧版本可继续读取和执行。

**交付物**

- Parser/Normalizer 模块。
- AST 序列化样例和执行计划哈希。
- 解析错误码和位置协议。

**测试**

- 单元测试：算术、条件、逻辑、嵌套、括号优先级。
- 安全测试：导入、属性、下标、循环、动态调用、超深 AST。
- 回归测试：现有公式编译结果不变。

### P0-C：目录和校验 API

**任务**

- 新增 `GET /api/v1/factors/formula-catalog`。
- 将字段、函数、签名、参数范围、示例和启用状态统一由后端返回。
- 扩展 `/factors/validate` 返回错误位置、依赖、窗口、返回类型、复杂度和覆盖率。
- 新增 `/factors/compile` 纯编译接口，不落库。
- 统一错误码和前端本地化映射。

**交付物**

- Pydantic 请求/响应模型。
- OpenAPI 契约和接口测试。
- 前端目录数据 Mock。

## 5. P1：前端编辑器升级

### P1-A：函数辅助模式

**任务**

- 保留现有 Modal、左侧树、中央编辑区和底部操作栏。
- 增加 `函数辅助 / 高级表达式` Segmented 控件。
- 左侧目录改为 API 驱动，保留当前搜索和分类交互。
- 点击函数在光标位置插入模板，不覆盖既有内容。
- 插入后自动选中第一个参数。
- 增加最近使用、常用模板和已保存因子分组。

**交付物**

- `FactorFormulaBuilder` 重构。
- 目录 Loading、Empty、Error 和禁用状态。
- 字段/函数 Tooltip。

**验收**

- 前端所有可见函数均能通过后端校验。
- 点击、拖拽和搜索不会丢失当前公式。

### P1-B：高级表达式和上下文帮助

**任务**

- 增加自动补全和括号匹配。
- 支持 `Ctrl/Cmd + Enter` 编译预览、`Ctrl/Cmd + Space` 补全。
- 根据光标位置显示函数签名和当前参数。
- 行内标记未知字段、未知函数、类型错误和窗口错误。
- 增加格式化撤销、保存草稿和未保存变更提示。

**交付物**

- 编辑器语法高亮和诊断层。
- 右侧上下文帮助面板。
- 窄屏底部抽屉适配。

### P1-C：后处理和预览

**任务**

- 将参数 JSON 改为动态表单，并保留高级 JSON 查看入口。
- 增加缺失值、去极值、标准化、中性化配置。
- 扩展预览参数：股票、日期、窗口、样本数和缺失策略。
- 预览显示覆盖率、缺失率、分布、异常值和耗时。
- 数据覆盖不足时给出阻断原因和可执行建议。

**交付物**

- 后处理配置组件。
- 预览结果表和诊断摘要。
- Preview Loading、Empty、Blocked、Error、Ready 状态。

### P1-D：保存和生命周期门禁

**任务**

- 保存时由后端重新编译并生成 AST、依赖和执行计划哈希。
- 增加 `dsl_version`、`source_mode`、`return_type`、`parse_source`。
- 编译失败只能保存 draft。
- candidate 提交前强制通过数据就绪和校验门禁。
- 保留现有人工审批、Shadow 和回退流程。

**交付物**

- FactorVersion 写入逻辑。
- 版本详情中的编译信息和依赖摘要。
- 生命周期回归测试。

## 6. P2：复杂因子和专业评估

### P2-A：因子引用

**任务**

- 新增 `factor_ref(code, version)` 函数。
- 固定引用版本并检查返回类型、频率和资产范围。
- 构建依赖图并检测循环依赖。
- 阻止被引用版本原地修改。

### P2-B：执行和评估优化

**任务**

- 对规范 AST 做执行计划缓存。
- 计算并展示复杂度、最大窗口和预计计算成本。
- 接入 IC、Rank IC、分层收益、换手率、行业暴露和 Shadow 观察。
- 评估结果关联具体 FactorVersion 和执行计划哈希。

## 7. 测试计划

### 后端

- DSL Parser 单元测试。
- AST 安全拒绝测试。
- 函数目录契约测试。
- 编译、依赖和哈希稳定性测试。
- 预览接口和数据覆盖率测试。
- 旧公式、旧版本和生命周期回归测试。

### 前端

- `FactorFormulaEditorModal` 交互测试。
- `FactorFormulaBuilder` 目录、搜索、插入和 Tooltip 测试。
- 模式切换结果一致性测试。
- 自动补全、参数提示、行内错误和快捷键测试。
- Loading、Empty、Blocked、Error、Preview Ready 状态测试。
- 桌面宽度、窄屏和右侧面板折叠的布局测试。

### 端到端

```text
创建 draft
→ 输入复杂 DSL
→ 实时校验
→ 修复错误
→ 预览样本
→ 保存 FactorVersion
→ 提交 candidate
→ 进入现有生命周期
```

## 8. 发布和回滚策略

1. 先以 feature flag 关闭新 DSL 入口，保留旧编辑器。
2. P0 完成后只开放编译和预览，不改变生产因子执行。
3. P1 完成后对新建因子默认启用函数辅助模式，旧因子继续使用旧版本编译路径。
4. 通过回归、黑盒和人工验收后，再逐步扩大新 DSL 的函数范围。
5. 任一阶段失败时关闭 feature flag，回退到旧编辑器和旧因子执行路径。
6. 不删除历史公式、历史 AST 或旧版本数据。

## 9. 最终完成定义

当以下条件全部满足时，视为本项目完成：

- 专业用户可以用 DSL 写出包含条件分支、逻辑运算、时间序列和常用量化函数的复杂因子。
- 普通用户可以通过函数目录、参数面板和条件配置器完成同一因子定义。
- 两种编辑方式生成等价 AST 和等价预览结果。
- 每个公式都能被校验、预览、版本化、追踪和回滚。
- 公式不会执行任意代码，不会引入未来数据，数据覆盖不足时不会绕过评估门禁。
- 当前因子中心、回测、预警、复盘、FactorSet 和模型流程回归通过。
