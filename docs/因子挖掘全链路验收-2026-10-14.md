## 修复后的执行关系

锁定股票池快照 → 保存本次日期、持有期、切分比例和进化配置 → 按冻结范围计算公式 → 使用真实持有期收益标签 → 按调仓日采样 → 验证集指导进化 → 固定测试集最终评估 → 登记因子版本 → 加入草稿集合 → 冻结集合并交给模型训练。

最终测试、模型训练、生产模型启用是不同操作。挖掘完成不会自动激活模型或触发交易。模板保存与经验记录进入各自的实际存储；经验库尚未成为自动进化的学习反馈源。
