4运行时与生命周期

FastAPI lifespan 统一托管所有后台循环；关闭时按序优雅退出，避免线程泄漏与 DuckDB 锁残留。

启动（startup）

  • ① initialize_runtime_database()：优先 DATABASE_URL → 其次 config/db_config.json → 最后 SQLite
  • ② init_db()：建表 + 自动对齐 schema + 修复基础数据完整性
  • ③ 启动清理：孤儿异步任务置 interrupted、过期挖掘结果删除、僵尸标的下线、因子流水线任务恢复
  • ④ 拉起 4 个常驻循环：定期清理（30 min）· 调度器 · 通知 Outbox · Universe 自动初始化

关闭（shutdown）

  • ① request_all_workers_stop() 请求同步工作线程提前让出
  • ② wait_workers_stopped(30s) 等待，超时则标记 graceful_interrupted
  • ③ shutdown_factor_warehouse_pools() 关闭 DuckDB 连接池
  • ④ 取消 asyncio 任务 → 关闭探测线程池 → mgr.dispose() 释放数据库引擎

关键架构约束

  • 层间单向依赖，服务层不得反向引用路由层
  • 因子域内部 ORM/服务禁止域外直连（conftest 有导入门禁）
  • 所有对外异常必须收敛为 UserError，敏感信息经 sanitize_message 脱敏
  • MySQL 连接错误禁止暴露明文密码
  • 关键数据操作必须 commit 后再继续后续处理
  • 第三方库（akshare/sklearn）缺失时用 MagicMock stub 兜底，不得阻断导入
