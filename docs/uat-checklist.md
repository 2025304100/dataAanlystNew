# UAT 手动测试清单（v3 稳定性聚焦）

## 前置准备

- 启动后端：`python -m uvicorn app.main:app --host 0.0.0.0 --port 8000`
- 启动前端：`cd frontend && npm run dev`
- 浏览器打开 `http://localhost:5173`
- 确认数据库已初始化（有持仓/观察池数据更佳）

## 0. 稳定性核心验证（最高优先级）

### 0.1 接口探测不再卡死

**操作路径**：设置 → 接口管理

- [ ] **单接口探测 30s 内返回**：点击任一接口的「探测」按钮，30 秒内必有反馈（成功/失败/超时）
- [ ] **探测超时显示明确错误**：若数据源不响应，探测结果显示 "probe timeout (30s)" 而非永久 loading
- [ ] **探测超时记录到 DB**：超时后接口状态列显示红色「失败」，错误信息含 "timeout"
- [ ] **批量探测 3 个一组并发**：点击「批量探测」，观察多个接口同时显示 loading（而非串行）
- [ ] **批量探测期间禁用单个按钮**：批量探测进行时，所有单个「探测」按钮 disabled
- [ ] **批量探测 180s 内完成**：17 个接口全部完成（最坏 6 批 × 30s = 180s，vs 串行 510s）
- [ ] **批量探测汇总提示**：完成后显示 "OK (N)" 或 "N OK, M failed"

### 0.2 机会挖掘全量同步不再卡死

**操作路径**：机会挖掘 Tab

- [ ] **创建全量同步任务**：scope=cn-stock, symbol_limit=10000, dataMode=sync，点击「开始」
- [ ] **单 symbol 卡死时 90s 跳过**：任务运行中，若某 symbol 卡死，90s 后跳过继续下一个
- [ ] **卡死 symbol 计入 failed_count**：进度区域 failed 数字递增，错误详情含 "同步超时"
- [ ] **进度条持续前进**：processed 持续递增，不永久停滞
- [ ] **watchdog 心跳更新**：任务 running 时 updated_at 每 30s 前进（前端轮询可见进度刷新）
- [ ] **卡死检测警告**：任务 running 但 2 分钟无进度更新 → 显示黄色「任务可能卡死」Alert
- [ ] **Alert 含取消按钮**：警告 Alert 内有「取消任务」按钮，点击后任务变 cancelled
- [ ] **STALE 自动中断**：任务 running 超 10 分钟无更新 → 自动标记 failed，message="任务长时间无进度，已自动中断"

### 0.3 universe 刷新超时保护（v3 新增）

**验证路径**：后端日志 + 机会挖掘 Tab

- [ ] **universe 刷新 120s timeout 生效**：创建 cn-stock 全量任务，若 universe 拉取卡死，120s 后任务标记 failed（不永久卡在 prepare 阶段）
- [ ] **universe 超时返回 None**：后端日志含 "universe refresh TIMEOUT after 120s"
- [ ] **universe 超时记录 ERROR 日志**：日志级别为 ERROR，含 scope 信息
- [ ] **prepare 阶段 watchdog 不更新 updated_at**：任务在 prepare 阶段时，updated_at 不前进（让 _expire_stale_tasks 10min 阈值能兜底）
- [ ] **universe 刷新 seen=0 中止任务**：若 universe 返回 seen=0，任务立即 failed，message 含 "universe 为空"

### 0.4 watchdog 阶段感知心跳（v3 新增）

**验证路径**：后端日志 + 任务状态

- [ ] **sync 阶段 watchdog 正常心跳**：任务在 sync 阶段时，updated_at 每 30s 前进
- [ ] **prepare 阶段 watchdog 跳过心跳**：任务在 prepare 阶段时，updated_at 不变（后端日志含 "skip heartbeat in prepare stage"）
- [ ] **终态任务 watchdog 立即退出**：任务 done/failed/cancelled 后，watchdog 线程不再心跳（后端无 "heartbeat" 日志）
- [ ] **watchdog 异常记录 WARNING**：DB 异常时日志含 "heartbeat failed"（非静默吞没）
- [ ] **连续探测不退化**：同一接口连续探测 5 次，响应时间不显著增加（验证独立线程池未泄漏）

### 0.5 日志可观测性（v3 新增）

**验证路径**：后端控制台/日志文件

- [ ] **探测 start 日志**：探测开始时输出 "probe {api_key} start" INFO 日志
- [ ] **探测 done 日志**：探测成功时输出 "probe {api_key} done: success=... latency=...ms" INFO 日志
- [ ] **探测 timeout 日志**：探测超时时输出 "probe {api_key} TIMEOUT after 30s" WARNING 日志
- [ ] **探测 exception 日志**：探测异常时输出 "probe {api_key} EXC: ..." WARNING 日志（含 exc_info）
- [ ] **universe 刷新 start/done 日志**：universe 刷新开始和完成时输出 INFO 日志
- [ ] **单 symbol 同步 start 日志**：每个 symbol 同步开始时输出 "sync_one {symbol} start" INFO 日志
- [ ] **akshare 重试日志**：akshare 调用失败重试时输出 INFO 日志（含 attempt 次数）
