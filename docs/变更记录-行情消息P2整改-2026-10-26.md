## 3. 业务契约与兼容说明

### 3.1 标签来源与历史保护

- 新建/采集自动识别的标签记录`sector_tag_source=auto`，自动识别没有结果时存空字符串。修改标题或摘要会重算自动标签。
- 显式提供`affected_sectors`字符串（包括空字符串）表示人工指定，记录`manual`；之后编辑文本保留人工标签。重复ID去重。
- `affected_sectors=null`或`sector_tag_source=auto`表示显式恢复自动识别，使用当前DB词库。两者与手工标签同时提交时，自动模式优先。
- 存量非NULL标签没有可靠来源信息，保留为`legacy`，不凭`is_manual`猜测标签是否人工指定，不在迁移或文本编辑中自动覆盖。详情会显示“历史标签（来源未记录，保留原值）”，用户可点击“切回自动识别”。
- 存量NULL标签表示未分类；列表、详情及热点用同一批当前词库现算，不回写。明确存储的空字符串表示“不含板块”，不再自动回退。
- 删除某个自定义关键词配置，只停止今后的该规则匹配，不删除已有事件中的历史板块ID。历史/未知ID以通用元数据展示，不因前端知识库缺少图标而丢弃。
- 调整词库影响新自动打标、自动标签文本变更、NULL历史回退；不会批量改写已有存储标签。本轮未建立历史规则版本库。

### 3.2 查询与分页

GET `/api/v1/market-events`保留原参数，并增加：

| 参数/响应 | 含义 |
|---|---|
| include_expired | 默认true，兼容主题管理等旧调用；行情页面传false，在COUNT及分页前排除expires_at早于as_of的行；NULL/恰等于边界保留 |
| event_ids | 可选重复查询参数，一次最多200个；空收藏不会退化成未筛选查询。前端收藏按100个ID分批，使用相同关键词/时间/方向/等级条件 |
| as_of | 首次响应的UTC时间，后续页复用，避免翻页过程中仅因时钟推进导致有效期漂移 |
| snapshot_max_id | 首次读取的新增记录ID上界，后续页复用，避免新插入事件挤动offset分页；点击刷新或采集后重新读取上界 |
| total | 当前完整筛选结果数量，不再被前端覆盖为当前页长度 |
| expired_total | 同筛选条件及ID上界下已过期的数量，用于隐藏提示；不计入active分页total |

每页50条；筛选、排序、收藏范围改变时回第1页。结果减少导致当前页超界时自动转到有效末页。类别卡维持既有全库维度口径，但不再将全表实例加载进内存；active查询时类别卡也排除过期数据。

查询/收藏/导出均使用GET，不修改只读验收服务的POST拦截规则，也不增加能绕过只读门禁的通用请求标记。

### 3.3 完整导出

- 导出捕获点击时的筛选、收藏集合及读取上界，按每页200条完整读取，使用与列表相同的排序兜底规则。收藏ID同样分批，首屏之外的收藏可查、可导出。
- 页面数/total变化、重复ID、提前空页、任一页失败会中止；改变筛选或离开页面后停止后续读取，不下载已读取的部分CSV。
- CSV包含UTF-8 BOM、标准双引号转义和CRLF；摘要换行按原界面导出约定压平；公式样式的外部文本增加文本前缀，降低表格软件执行公式的风险。
- 读取上界与as_of是轻量一致性措施，**不是跨HTTP请求的数据库事务快照**。读取期间若旧记录被编辑/删除仍可能变化；已检测的数量/重复异常会提示刷新重试，无法保证识别所有“数量恰好不变”的并发修改。
