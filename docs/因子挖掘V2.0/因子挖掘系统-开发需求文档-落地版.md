### 0.3 v3.2 本轮修订

**修正 1 项事实性错误**

- §6.8 因子质量分级**：删除"新需求待确认"的错误结论**。该分级（8 维度 + S/A/B/C/D 五级阈值 + 动态调整 + D 级作负样本）已在评审前的对话中完整对齐，此前"全 docs 目录零命中"的结论源于**检索方法缺陷——只 grep 了 `docs/` 目录，未检索历史对话记录**。现按已对齐规格完整填入 §6.8（标注"默认值，可在设置页调整"），无需重新讨论。

**补齐 3 项逻辑缺口**

1. **月频统计降级**（逻辑缺口 1）：月频 test 仅 12 点，Bootstrap/置换无意义 → 月频**不做 Bootstrap/置换**、只报 t 检验参考值、**最高只能评 B 级**、不切 holdout；想评 S/A 必须镜像 10 年
2. **`ts_delta` 的 n 单位歧义**（逻辑缺口 2）：拆为 `ts_delta_bars`（交易日）/ `ts_delta_periods`（报告期）两个显式算子，避免 AST 隐式解释导致质量类模板算错
3. **行业内中性化缺数据前置**（逻辑缺口 3）：需行业历史版本数据 + PIT 化，当前无此准备 → **整体移至二期**，M2 只做全市场/候选池横截面

**处理 3 项小点**

- AI 最坏情况占比：10×8=80 个叠满损耗后约 49 个 < 57，注明"随机补足、实际占比可能低于配置值"，非缺陷
- Walk-Forward：注明"窗口滚动重叠约 1.5 年，非独立样本，仅作方向一致性观察，不作独立统计检验"
- M1 拆分：为降低集成风险，M1 内部分 **M1a（数据与 DSL 地基，3-4 周）** 与 **M1b（进化闭环，3-4 周）** 两个可验证节点

**性质定义**

1. 因子挖掘是**因子中心内的研究实验**，不是因子模型训练，不是独立系统。
2. 所有结果写入现有数据库与任务体系，禁止以 JSON 文件目录作为唯一事实来源，禁止绕过 Facade 直连其他业务域表。
3. 本期实现**遗传算法范式**：初始种群 → 逐代进化（选择→变异→交叉→评估）→ 收敛判断 → 最终全量验证 → 结果输出。

## 1. 定位与范围

### 1.1 本期链路（Q1：止步于候选产出）

```text
选择股票池/数据截止日 → 生成训练物料与候选池看板
→ 时间与目标 → 字段与异步校验 → 进化参数 → 进化执行
→ 候选因子产出（IC/ICIR/覆盖率/分层收益 + 统计校正）
→ 人工确认 → 加入 draft FactorSet
→ 〔跳转〕设置 → 因子模型页（训练/影子/激活，不在本模块范围）
```

**边界红线**：本模块**不执行** Ridge 训练、评分生成、模型激活。结果页提供「去因子模型页训练」按钮，携带上下文：

| 携带字段 | 说明 |
|---------|------|
| `factor_set_id` | 目标 draft FactorSet |
| `data_cutoff_at` | 数据截止日 |
| `candidate_pool_snapshot_id` | 股票池快照 |
| `rebalance_frequency` | 调仓频率 |

**候选池看板交互**（小问题 15 补充）：

| 状态 | 行为 |
|------|------|
| 初始 | 筛选/导入可交互，按钮「生成训练物料」 |
| 分析中 | 按钮 loading「正在分析候选池特征…」（2~15 秒） |
| 分析完成 | 按钮变「查看候选池看板」；**筛选/导入/批量删除全部锁定置灰**，顶部黄色提示条 |
| 看板弹窗 | 只读；含概览卡片、市值分布、行业分布、风格暴露、市场环境、数据质量 |
| 「重新选择」 | 二次确认 → 清除分析数据、释放锁定、回到初始 |
| 「下一步」 | 进入 Step 2 |

看板结果（市值分布、行业分布、风格暴露、市场阶段、因子类型建议）作为 Prompt 变量传入 Step4 的 AI 生成。

## 2. 数据基线

### 2.1 镜像后能力（Q4：默认 5 年）

| 项 | 值 |
|---|---|
| 日线区间 | 2021-01-01 ~ 2026-09-07（约 5 年 / 1,215 交易日） |
| 标的数 | 5,072 ~ 7,270 |
| 日频有效调仓点 | 约 1,215（门槛 252） |
| 周频有效调仓点 | 约 243 |
| 月频有效调仓点 | 约 60 |

**样本量口径澄清**（小问题 12）：需求原文「生产建议周频不少于 156 点、月频不少于 60 点」指**总有效调仓点**，不是训练段点数。

| 频率 | 总点数 | 生产建议线 | train(60%) | val(20%) | test(20%) | 余量 |
|------|-------|-----------|-----------|----------|-----------|------|
| 周频 | 243 | 156 ✅ | 146 | 49 | 49 | 健康 |
| 月频 | 60 | 60 ✅（压线） | **36** | 12 | 12 | **无余量** |
| 日频 | 1,215 | — | 729 | 243 | 243 | 健康 |

**月频统计降级规则**（逻辑缺口 1）：月频 test 段仅 **12 点**（自由度 11），Bootstrap/置换重采样几乎全是重复样本，**统计上无意义**。因此月频明确降级：

| 项 | 月频处理 |
|---|---------|
| Bootstrap / 置换检验 | **不做**（样本不足），仅报告 t 检验参考值 |
| 因子质量分级 | **最高只能评 B 级**（与"样本不足最多 B 级"原则一致） |
| 切分 | **不再切 holdout** |
| 想评 S/A 级 | **必须镜像 10 年数据**（月频约 120 点，test 24 点） |

前端需在结果页对月频任务显式提示该降级规则。

### 2.2 历史数据镜像功能

| 项 | 内容 |
|---|------|
| 入口 | 设置 → 数据中心 |
| 区间 | 5 年（默认 2021-01-01 起）／10 年（2016-07-12 起）／全量 |
| 执行 | 异步任务 + 进度 + 通知（复用 `async_tasks` + 通知 Outbox） |

- 前端提示**幸存者偏差**风险：长期回测中已退市标的缺失会高估因子表现

## 3. 产品硬规则

### 3.1 双任务锁（Q6）

| 锁 | 范围 | 冲突行为 |
|---|------|---------|
| `mining_domain` | `task_type='factor_mining'` | 域内唯一，判定 `(queued, running)`；有则**拒绝** |
| `duckdb_write` | 所有写 DuckDB 的任务 | 互斥；被占则**排队** |

提交流程：查 `mining_domain`（有则拒）→ 查 `duckdb_write`（空闲执行 / 被占排队）→ 完成/失败/取消释放并**自动拉起队首** → **心跳 30 分钟**（可配置）超时释放。心跳更新点：每代结束 + 最终验证每完成 10 个因子。

前端：Step4 显示「可立即开始」或「将排队（前面 N 个）」；Step5 显示排队位次 / 预计等待 / 取消排队；锁异常释放消息通知。ETA 为规则估算，标注「估算」。

### 3.2 过拟合防线（v3.1 拆两层，修复硬伤 2、3）

#### 第一层：数据层（M1 必须，地基）

1. **三段切分** train(60%) / val(20%) / test(20%)，比例作用于有效调仓点，禁止随机切分
2. **purge / embargo**：训练-验证间 purge、验证-测试间 embargo，避免持有期标签跨边界穿越
   > 底座 `factor_evaluator.TimeSplit` **已实现**（`purge_days=5`、`embargo_days=5`、`target_horizon`），M1 直接接入，无需新建
3. **适应度只用 train**：进化中计算 ICIR/覆盖率/换手率的样本**只取 train 段**
4. **val 段 M1 不使用**（固定代数跑完）；M2 起 val 仅用于 D1 早停信号与 C1 参考，**不参与适应度计算与选择**（修复硬伤 3）
5. **test 全程锁定**：test 段仅在用户点「最终确认」时评估一次，**评估后禁止回炉重挖**
6. **最小样本量硬门槛**：日频 252 / 周频 104 / 月频 36 有效调仓点
7. **研究声明**：结果页强制标注「研究结论，不代表可交易策略」

> **M1 不做数据层 = M2 推倒重来**：进化评估逻辑、G2 缓存哈希（含数据快照范围）、预筛流程全部依赖切分。

#### 第二层：统计层（M2）

| 方法 | 口径 | 用途 |
|------|------|------|
| t 检验 | p < 0.05 | IC 显著非零 |
| Bonferroni | 按 Top50 校正，p < 0.001 | 多重检验保守校正 |
| FDR | q < 0.1 | 多重检验平衡校正 |
| Bootstrap | 1,000 次 | ICIR 置信区间 |
| 置换检验 | 1,000 次 | 与随机因子对照，排除运气 |
| **Deflated Sharpe** | 记录 `total_trials` | 校正试验次数带来的选择偏差 |
| **衰减率** | `test_ICIR / train_ICIR` | **< 0.5 标记疑似过拟合，不得给 B 级以上** |
| **Walk-Forward** | 3~4 个滚动窗口 | 跨时段稳健性；镜像 10 年时可加第 4 段 holdout。**窗口滚动重叠约 1.5 年，非独立样本，仅用于跨时段方向一致性观察，不作为独立统计检验**（小点 2） |

结果页同时显示**原始 ICIR 与校正后 ICIR**。

### 3.3 AI 生成约束（v3.1 补齐遗漏 5、6）

**批量生成口径澄清**：单次挖掘 **10 次调用**，每次让 AI **批量返回 8~12 个骨架**，合计约 80~120 个；经校验、去重、冗余后保留约 57 个。**不是 10 个骨架**。

> **最坏情况占比说明**（小点 1）：按下限 10×8=80 个、叠满三层损耗（校验 15% + 来源内去重 20% + 跨来源去重 10%）后仅剩约 **49 个 < 目标 57**。此时由随机补足差额，**AI 实际入库占比可能低于配置的 57%**，属预期行为，不视为缺陷。前端可展示"AI 实际入库 / 目标"供参考。

| 项 | 值 |
|---|-----|
| 单次挖掘调用上限 | 10 次（每次批量 8~12 个骨架） |
| 并发 | 4 路（`ThreadPoolExecutor` + `asyncio.to_thread`） |
| 单次超时 | 30 秒 |
| **AI 环节总超时** | **5 分钟**（超出则剩余名额全部回退随机） |
| **成本上限** | **¥10 / 500k token**（达上限停止调用，名额回退随机） |
| 失败/超时/校验不通过 | 名额回退**受约束随机**补位 |
| 用户开关 | Step4「启用 AI 生成」默认开 |

**强制输出字段（遗漏 5）**：AI 每次输出必须包含，缺任一则丢弃该骨架、名额回退随机：

| 字段 | 说明 |
|------|------|
| `formula_ast` | 公式抽象语法树 |
| `category` | 6 类之一 |
| `economic_logic` | **自然语言经济逻辑** |
| `expected_direction` | 预期方向（正向/反向） |

`candidates` 表新增：`economic_logic` / `expected_direction` / `interpretability_score` / `logic_source`（`ai`/`template`/`manual`）。

**M1 验收**：AI 生成因子可查看经济逻辑，**缺逻辑的不入库**。

## 6. 功能需求

### 6.0 DSL 扩展（Q5 + 补 `ts_delta_bars`/`ts_delta_periods`/`ts_atr`，遗漏 9）

**背景**：现有 `rank`/`zscore` 是**后处理配置项**（`apply_postprocess(values: pd.Series, ...)` 只对最终因子值处理一次），无法表达 `cs_rank(A) - cs_rank(B)`；白名单无 `delta`/`atr`，导致 25 个模板中 10 个不可行。

**新增截面算子族 `cs_`**

| 算子 | 语义 |
|------|------|
| `cs_rank(x)` | 横截面百分位排名 |
| `cs_zscore(x)` | 横截面标准化 |
| `cs_demean(x)` | 横截面去均值 |
| `cs_scale(x)` | 横截面缩放到单位和 |
| `cs_quantile(x, n)` | 横截面分位组编号 |
| `cs_winsorize(x, n)` | 横截面去极值 |

**新增时序算子 `ts_`**（遗漏 9）

| 算子 | 语义 | 实现要点 |
|------|------|---------|
| `ts_delta_bars(x, n)` | **行情**字段 N 个交易日差分 | 如 `ts_delta_bars(close, 20)` = 20 个交易日 |
| `ts_delta_periods(x, n)` | **财报**字段 N 个报告期差分 | 如 `ts_delta_periods(roe_ttm, 4)` = 4 个报告期（季度），**不是 4 个交易日** |

> **`n` 单位歧义必须拆算子解决**（逻辑缺口 2）：行情与财报的采样频率不同（交易日 vs 报告期），若共用一个 `ts_delta`，AST 需按字段类型隐式解释 n，极易算错质量类模板。**拆为两个显式算子**，语义无歧义，由公式编写者在编写时明确。
| `ts_atr(x, n)` | 平均真实波幅 | **内部用 `ref(close, 1)` 计算 prev_close**（日线表无 `prev_close` 列，无需补数据） |

**实现要求**

1. AST 节点标注计算方向（时序 / 横截面），嵌套时**从内到外逐层计算**
2. DuckDB 按 `trade_date` 分组向量化
3. 横截面范围 M1/M2 支持**全市场 / 候选池**；**行业内中性化移至二期**（数据前置未就绪，见下）
4. 方言归一：`std`→`stddev`、`llv/hhv`→`lowest/highest`、`turnover`→`turnover_rate`；撤销 `prev_close` 虚注册
5. 后处理配置项保留，与公式内算子并存

### 6.1 候选生成（遗传算法）

输入：`universe_id`/股票池快照、`data_cutoff_at`、调仓频率、目标周期、种群大小、最大代数、选择比例、变异率、交叉率、随机注入率、收敛阈值、随机种子、初始种群来源配置。

**两层结构**

- **第一层 经典底座**：25 个系统预设模板（6 类），参数网格展开；可勾选类别（默认全选）、数量上限（默认 40，硬上限种群 60%）、覆盖策略（均衡覆盖默认 / 优先级覆盖）。字段联动：估值/质量类未选对应字段则该类置灰。
- **第二层 AI/随机探索**：剩余名额 = 种群大小 − 经典实际入库数。AI 生成（默认剩余 57%，受 §3.3 约束）、受约束随机（43%，算子 ≤4、嵌套 ≤2、字段引用 ≤3）。

**数量链路**：各来源按目标 × 冗余系数（默认 2.0）超额生成 → 校验（损耗 10~20%）→ 来源内去重（15~25%）→ 跨来源去重（约 10%）→ 按「锁定经典 → AI 取 Top → 随机补足」入库。

**四层去重**：①生成时规避 ②`formula_hash` 精确去重（交换律归一）③AST 结构相似度聚类（**M1 简化相似度，M2 树编辑距离**）④运行时因子值相关性去重（三层指纹预筛，≥0.95 标记 `eliminated_similar`）。

**逐代进化**：评估（短样本，**只用 train 段**）→ 观测 → 选择 → 繁殖 → 校验 → 停止。**M1 朴素选择（按 ICIR 排序）+ 固定三率；M2 换完整机制。**

**候选记录字段**：公式哈希、规范化公式、表达式树、字段依赖、代数、父代 ID、操作类型、随机种子、生成时间，及 §3.3 新增的 `economic_logic` / `expected_direction` / `interpretability_score` / `logic_source`。

#### 6.1.1 选择机制（M2）

- **A1 赛道竞争**：6 类赛道，归类优先级 `quality > valuation > volatility > volume_price > reversal > trend`；配额「保底 60% + 动态 40%」，弱赛道（连续 3 代最优个体处于最差层）保底减半转出
- **B1 多目标 NSGA-II**：默认 4 目标（ICIR↑、覆盖率↑、换手率↓、复杂度↓）；非支配分层得 rank + 拥挤度 CD，比较「先比 rank、同 rank 比 CD」；目标数限 3~5
- **B2 锦标赛**：赛道内随机抽 K=3（可调 2~7）取最优；精英不参与
- 偏好档位（均衡/稳健/进攻/简洁）**只作用于结果排序**

#### 6.1.2 繁殖与自适应（M2）

观测(D3/D1) → 决策(C1) → 执行(C2/C3/D2) 单向信号流：

| 机制 | 唯一职责 |
|------|---------|
| D3 多样性监控 | 只产健康分信号，**不改任何率** |
| C1 自适应调度 | **唯一调参者** |
| C2 四种变异 | 参数微调/算子替换/字段替换/结构变异，比例由 C1 定 |
| C3 子树交叉 | 同/跨赛道比例由 C1 定（基准 80/20） |
| D2 随机注入 | 注入率由 C1 定（0.05~0.20） |
| D1 收敛早停 | 只判断停止；**读 val 段信号，先自救（stall≥2），再连续 3 代无效才停** |

安全护栏：变异 [0.40,0.80] / 交叉 [0.10,0.50] / 注入 [0.05,0.20]，三率和为 1；单次调幅 ≤0.10；精英不参与变异交叉。

### 6.8 因子质量分级（M2，规格已对齐）

**8 个评分维度**：统计显著性、经济显著性（ICIR / 分层收益）、稳定性、覆盖率、换手率、复杂度、与已有因子相关性、OOS 表现。

**五级阈值（每一级要求全部满足才定级）**：

| 级 | ICIR | 显著性 | Bootstrap CI 下限 | 置换检验 | 覆盖率 | OOS 表现 | 相关性 | 换手率 | 复杂度 |
|---|------|--------|------------------|---------|-------|---------|-------|-------|-------|
| **S** | ≥0.5 | Bonferroni 后 p<0.01 | >0.1 | p<0.001 | ≥90% | ICIR≥0.3 且同向 | <0.7 | <30% | ≤4 算子 |
| **A** | ≥0.3 | 校正后 p<0.05 | >0 | p<0.01 | ≥80% | 同向 | <0.8 | <50% | ≤6 算子 |
| **B** | ≥0.2 | 原始 p<0.1 | >−0.05 | — | ≥70% | ICIR>0 且 <0.2 | <0.9 | — | — |
| **C** | ≥0.15 | p<0.2 | — | — | ≥60% | 样本内有效但 OOS 不稳 | — | — | — |
| **D** | <0.15 | 或 p≥0.2 | — | — | 或 <60% | 或 OOS 反向 | 或 ≥0.95 | — | — |

**等级含义**：S 高置信可进入 shadow；A 统计显著建议 Testing；B 可用但需观察；C 边际仅作研究；D 不达标不入 FactorSet。

**动态调整（每季度重评）**：

- B 级**连续 2 季稳定**可升 A
- S/A 级**连续 2 季下滑**（ICIR 降幅 >30% 或 OOS 反转）→ **降级并移出 FactorSet**
- **D 级因子结构存入 F1 作负样本**（供后续抽取时规避）

**约束**：衰减率 `test_ICIR / train_ICIR < 0.5` 的因子**不得评为 B 级以上**（§3.2）。

> 上述阈值为**默认值，可在设置页调整**。依赖 test 段结果与 p 值，故随 M2 统计层一并实现。

**月频特例**：月频因子**最高只能评 B 级**（见 §2.1，test 段仅 12 点，统计检验无意义）。
