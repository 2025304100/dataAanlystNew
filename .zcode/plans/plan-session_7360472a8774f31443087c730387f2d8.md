- **数据隔离**：mysqldump 克隆 `gpfx` → `gpfx_validation` 副本库，可写后端用 `DATABASE_URL` 指向副本；正式库 gpfx 全程零改动

## Phase 3 今日决策 & 自动接管（核心链路）
1. preflight + today-preview（只读推演）
2. **阻断分支取证**：RECONCILIATION_BLOCKED 状态下请求 dry-run/execute → 预期 409 + blockers（异常分支证据）
3. **检查与对账解锁全流程**：reconciliation-preview → `POST reconcile` 执行对账 → 差异分析（MISSING_ORDER_PLAN/UNFILLED_PLAN/POSITION_MISMATCH/NAV_BROKEN 逐项）→ 修复（补证据/接受账户基线/repair 系列接口）→ 重跑对账至差异清零 → `POST confirm-reconciliation`（ack=true + ≥10 字备注 + report_id/version 校验）→ 状态回 READY、待处理数下降对照
4. `dry_run=true` execute → 只出计划不下单，核对 SimOrder 无新增
5. `dry_run=false` execute（真实模拟单）→ 核对 SimOrder/SimTrade/CashLedger/持仓/权益快照变化，**重点验证 d2f8c15d 提交的"非干运行自动 commit"行为**
6. 幂等分支：同日重复 execute → 验证幂等复用/拒绝
