本模块由三个入口文件组成：`main.tsx` 通过 `ReactDOM.createRoot` 挂载 `<AppProvider>` + `<AntdApp>` + `<ConfigProvider>`，将 antd locale、主题色（`#0f766e`）和 message API 注入到 `AppContext`；`App.tsx` 作为工作区主壳，基于 `ctx.activeTab`（decision/portfolio/opportunity/macro/news/settings/investment）条件渲染各业务组件（TodayDecision、PortfolioTradingShell、OpportunityCenter、MacroData、MarketNews、Settings），并通过 DetailModal/MetricModal 管理跨 Tab 的详情弹窗，同时用 `AIAssistantProvider` 包裹全局 AI 助手抽屉，并通过 `tabCompatibility.resolveTabFromUrl` 兼容旧深链接；`universe-standalone.tsx` 是独立的单页面入口，直接挂载 `UniverseDataPanel` 并固定中文 locale，用于脱离主应用单独部署。依赖方向单向向下：入口 → AppContext/i18n → 业务组件，壳层不持有业务状态，仅编排导航与全局 UI。
