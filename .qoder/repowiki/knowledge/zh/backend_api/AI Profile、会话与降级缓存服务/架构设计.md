本模块按职责拆分为四个独立服务文件，均基于 SQLAlchemy Session 操作 `app.models` 中的模型：
- `ai_profile_service.py`：Profile 的 CRUD、连接测试（httpx POST `/chat/completions`）、模型发现（GET `/models`）、用量计数与 SecretStore 集成，所有外部调用失败返回结构化结果而非抛异常。
- `ai_session_service.py`：AISession/AIMessage/AIActionAudit 的增删改查，采用软删除（status=deleted + deleted_at）和会话级 token 累计，对不存在记录抛出自定义 LookupError。
- `ai_cache.py`：基于 OrderedDict 的线程安全 LRU 内存缓存，key 为 `hash(prompt + context_version)`，TTL 默认 300s，通过 `get_ai_cache()` 暴露进程内单例。
- `ai_failover.py`：无状态 `AIFailoverManager`，依据 `health_status`、`priority`、`is_fallback`、`daily_request_limit` 选择可用 Profile，失败时按 fallback→次高优先级→本地 Ollama 顺序切换，连续失败阈值（3 次）将 degraded 转为 down。
- `ai_profile_migration.py`：启动时把旧 `ai_config.json` 幂等迁移为 AIProfile 记录，保留原文件并写入 `migrated=true` 标记。
依赖方向：failover → profile_service；migration → profile_service + secret_store；session/cache 不依赖其他服务，仅依赖 models。
