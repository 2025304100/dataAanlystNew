- 数据库操作统一通过 SQLAlchemy select + where + scalars().first()/all() 模式，避免使用 session.query 风格。
- 时间戳统一使用 datetime.now(timezone.utc).replace(tzinfo=None) 获取 naive UTC 时间，保持与模型字段一致。
- 金额与百分比计算后通过 round(..., 2) 或 round(..., 4) 截断，避免浮点精度累积误差。
- 撮合与成本计算采用无副作用的纯函数（match_order_plan、compute_cost、compute_fill_price_with_slippage），配置通过 dict 参数注入而非全局变量。
- 业务异常通过自定义 Exception（如 MemberHasPositionError）或 FastAPI HTTPException(status_code=400) 表达，错误信息包含 portfolio_id/symbol_id 等上下文键。
- 组合级策略通过 get_active_rule/get_default_portfolio 读取 is_active/is_default 标记的最近一条记录，并以 JSON 字段（stage_limits_json 等）承载扩展配置。
