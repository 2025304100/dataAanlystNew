- 对外暴露的查询/计算函数统一接收 SQLAlchemy Session 作为首参，并在内部自行构造 select 语句，避免在调用方拼装 SQL。
- 配置驱动：评分维度、权重、过滤阈值均以 JSON 结构（config_json）描述，计算逻辑通过 evaluate_dimension_scores/_aggregate_final_scores 解析而非硬编码分支。
- PIT 安全查询统一使用 factor_model_run_id + trade_date <= decision_date + factor_data_cutoff_at <= data_cutoff_at 三重约束，并以 ROW_NUMBER 窗口函数取每 symbol 最新记录。
- SFTP/外部数据失败采用“失败不阻断主流程”策略：_compute_external_factors 捕获异常并降级为缺失因子，由 missing_policy（neutral/penalty/ignore）决定分值。
- 候选池门禁与快照选取采用纯函数设计（无 DB 副作用），通过 pick_candidate_snapshot_rows 的 entry_point 参数区分 dry_run/backtest/auto_simulation 三种参考日期语义。
- 批量操作优先使用 in_(...) 子句与预加载字典（如 _batch_latest_scores、universe_map）消除 N+1 查询，返回统计计数（created/skipped/not_found）便于观测。
