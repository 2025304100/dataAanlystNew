本模块由两部分组成：
- `.github/workflows/test.yml`：单一工作流文件，按 job 划分四个并行阶段——backend-whitebox（Python 3.12 + pytest -m whitebox）、frontend（Node 20 + npm test）、backend-blackbox（启动 uvicorn app.main:app 并通过 /health 探测后运行 pytest -m blackbox）、e2e（同时拉起后端与 frontend dev 服务，安装 Playwright Chromium 后执行 tests/e2e/ -m e2e）。触发条件为 push/pull_request 到 main/master 分支。
- `.trae/documents/` 与 `.trae/specs/`：Trae IDE 专用的项目文档与规格目录，前者存放异步市场数据同步、专业版测试计划、稳定性修复与验证报告、工作台 UI 优化等说明；后者按功能域组织 specs（如 factor-evaluation-*、portfolio-factor-backtest-full-linkage、opportunity-center-* 等），作为 AI 辅助开发的上下文依据。
依赖方向单向：CI 仅消费仓库源码与 requirements.txt/frontend/package-lock.json，不反向影响业务代码；`.trae/` 仅为 IDE 提示与文档用途，不参与构建。
